# 그림 BGM 만들기 — 설계 문서

작성일: 2026-06-15
대상: 그림에 어울리는 30초 BGM을 학생이 직접 만드는 교실용 웹 창작 도구
현재 위치: `C:\Users\com\Desktop\baeum\song\sound-drawing-tool\`

---

## 1. 목표와 맥락

- **교육 목표**: 학생이 특정 그림(작품)을 올리고, 그 그림에 어울리는 30초 분량의 BGM을 단계별 선택과 드로잉으로 직접 완성한다.
- **교육적 설계 원칙**: 그림과 음악이 꼭 들어맞지 않아도 되지만, **지나친 불협화음은 피한다.** 그래서 음높이·박자를 음계와 4/4 격자로 자동 보정하는 "안전한 비계(scaffolding)"를 둔다.
- **사용 맥락**: 한국 학교 교실. **데스크탑(마우스) 전용.** 선생님이 폴더를 열어 실행·배포한다. 서버 없음(no-backend).
- **음원**: `sound/` 폴더에 국악(국립국악원)·서양(필하모니아)·배경(freesound)·자연효과음(유자레코즈)이 이미 존재. 향후 패드 음원(ambient/string/drone/choir/synth pad)을 추가로 교체·투입할 수 있게 설계한다.

## 2. 리서치 요약 — 무엇을 빌려오는가

- **Chrome Music Lab – Song Maker**: 격자 기반(가로=시간/8분음표, 세로=음높이)으로 "틀린 소리가 안 나는" 안전한 비계, 링크 공유.
  → 빌려옴: **음계·4/4 격자 자동 보정**, **레시피를 URL에 담는 공유 링크**.
- **Paint with Music (Google Arts & Culture / Magenta)**: 붓질→음(세로=음높이), 장면 캔버스(장면=분위기), 음계 가이드선.
  → 빌려옴: **드로잉→음높이 매핑**, **장면-소리 연결**, **음계 가이드선**.
  → 차이: Paint with Music은 '그리는 속도=음량'이지만, 본 도구는 **그리는 속도와 무관**하게 가로 위치만 시간으로 사용(교육적 공정성).
- **BandLab for Education**: 배경/선율/효과음을 레이어로 쌓는 트랙 구조, 과제 제출.
  → 빌려옴: **배경 패드 + 선율 + 자연 효과음 레이어 합주**, **완성작 내보내기(제출)**.

## 3. 확정된 결정 사항 (Decision Log)

| 항목 | 결정 |
|---|---|
| 디자인 방향 | **갤러리·아틀리에** (따뜻한 종이 톤, 작품/캔버스 중심, 분위기 색 무드 틴팅) |
| 주요 기기 | **데스크탑(마우스) 전용** |
| 그림 업로드 시점 | **1단계 맨 처음** — 이후 모든 선택을 그림을 보며 진행, 썸네일 상단 고정 |
| 연주 방식 | 드로잉을 마치면 **전체 30초를 한 번에 재생**(실시간 그리기-연주 아님) |
| "버전별로 듣기" | **학생이 만든 여러 시도(테이크)를 저장·비교** |
| 내보내기 | **오디오(WAV) + 커버 이미지(PNG) 다운로드** |
| 공유/저장 방식 | 서버 없이: 시도는 브라우저 localStorage(레시피만, 수 KB), 완성작은 로컬 다운로드, (보너스) 레시피 URL 공유 링크 |
| 시김새 | 단순 흉내가 아니라 꺾음·흘러내림·떠는음을 **음정 곡선으로 실제 구현** |
| 기술 범위 | **빌드/프레임워크 없는 단일 정적 앱** 유지. 기존 오디오 엔진 내부 재사용, UI/흐름/비주얼 대폭 재작성 |

## 4. 사용자 흐름 (5단계, 그림이 맨 앞)

```
1 그림·길이        2 분위기              3 악기            4 선율(음계)         5 드로잉·완성
업로드 + 15/30/45초  안개/숲/비오는밤/      서양·국악·전자     밝음/차분/신비/        그리기·듣기·시도저장·
                    바다/우주/명상                         자연/국악풍           비교·내보내기
```

- 그림 썸네일은 1단계 이후 상단(또는 사이드)에 **계속 노출**되어 "이 그림을 위한 선택"임을 상기시킨다.
- 길이에 따라 드로잉 팔레트 구간 수가 결정된다(예: 30초 → 10초 × 3구간).

## 5. 비주얼 — 갤러리·아틀리에

- 따뜻한 미술 종이 톤 배경, 넓은 여백. 헤드라인은 전시 라벨 느낌의 세리프, 본문은 깔끔한 한글 산세리프(시스템 폰트 스택 → 오프라인 안전).
- **무드 틴팅**: 선택한 분위기의 색(`atmosphere.color`)이 화면 전체 강조색으로 은은하게 번진다 → 장면과 화면이 연결.
- 드로잉 캔버스: 화첩 질감 + **음계 가이드 가로선**(Paint with Music식) + **팔레트 구간 분할선**(액자 분할처럼).
- 결과 화면: 업로드한 그림을 **액자에 건 작품**처럼 표시, 가운데 ▶ 버튼, 아래에 **미술관 명패**(제목·분위기·음계·악기).

## 6. 드로잉 → 음악 엔진 (핵심)

- **시간 매핑**: 가로축 = 시간. 그리는 속도와 무관하게, 그린 선(polyline)을 x축 기준 박자 격자에 다시 샘플링한다.
- **음높이 매핑·보정**: 세로축 = 음높이. 각 박자 위치의 y값을 선택한 음계의 **가장 가까운 음으로 스냅**한다.
  - 밝음 = C Major / 차분함 = A Minor / 신비로움 = D Dorian / 자연스러움 = (C) Pentatonic / 국악풍 = Pentatonic + 시김새.
- **리듬 자동완성**: 8분음표 4/4 격자에 정렬. 선이 비거나 희박한 구간은 쉼표로 처리. 큰 도약(>장6도 등)은 음계 내에서 완화.
- **선율형 / 리듬형 토글**:
  - 선율형(기본): 위 매핑대로 음을 연주.
  - 리듬형: 드로잉의 봉우리/밀도를 4/4 타격 패턴(온셋)으로 변환해 연주.
- 그린 원본 선과 보정된 음(점선)을 캔버스에 함께 표시해 학생이 보정 결과를 확인.

## 7. 오디오 구조

- **중앙 음원 매니페스트**: 역할(배경 패드 / 선율 악기 / 효과음) → 파일 경로 + 메타데이터(기준음 baseMidi, sampleMode: one-shot|phrase, duration).
- **레이어 합주**(Web Audio gain 그래프): 배경 패드 + 자연 효과음 + 드로잉 선율을 믹스.
- **장면 ↔ 패드 종류 매핑**: 각 분위기(scene)는 기본 패드 종류(ambient/string/drone/choir/synth pad) + 자연 효과음 묶음을 가진다. 선생님이 패드 종류별 실제 음원을 추가하면 매니페스트가 자동 연결한다. 패드 음원이 없으면 현재 `배경(freesound)` 파일을 임시 스탠드인으로, 그래도 없으면 합성음으로 대체.
- **샘플 피치 시프트**: 선율 악기는 단일음 샘플(예: `violin_A3`)을 baseMidi 기준 playbackRate로 음정 이동. 국악 긴 구절 음원은 phrase 모드로 구간 선택.
- **실제 음원 우선, 합성음 대체**: 파일 로드 실패 시 오실레이터 합성으로 자동 폴백(현재 강점 유지). 화면에 현재 사용 중인 음원/모드 표시.

## 8. 시김새(국악 표현) 엔진

국악풍 음계 또는 국악기 선택 시 음별 피치 엔벨로프를 적용한다.

- **꺾음(앞꾸밈)**: 음 시작에 빠른 윗꾸밈음 후 본음으로 안착(짧은 피치 상승→하강).
- **흘러내림**: 음 끝에서 다음 음을 향해 하강 글라이드.
- **떠는음(비브라토)**: 충분히 긴 음에 한해 일정 주기의 detune 진동.

구현: 샘플 소스는 `playbackRate` 자동화, 합성 폴백은 `frequency`/`detune` 자동화. 곡선은 음악적으로 조율(랜덤 흔들림이 아님). 강도는 음 길이와 "시김새 강조" 옵션에 연동.

## 9. 시도 저장·비교 (테이크)

- **테이크 = 레시피**: `{ duration, atmosphere, instrument, style, mode(선율/리듬), drawingPath, name?, createdAt }`. 오디오는 저장하지 않는다(수 KB).
- 저장 위치: 메모리 + **localStorage**(새로고침에도 유지). 오디오는 재생 시 매번 재합성 → 용량 문제 없음.
- UI: 결과 영역에 저장된 테이크를 **작은 액자 썸네일**(드로잉 선 + 분위기 색으로 렌더)로 모아 보여주고, 클릭하면 불러와 재생·비교.
- "이 시도 저장" 버튼으로 현재 상태를 테이크로 저장.

## 10. 내보내기

- **오디오(WAV)**: `OfflineAudioContext`로 전체 곡을 오프라인 렌더링 → AudioBuffer → WAV 인코딩(외부 라이브러리 없이) → 다운로드. 30초 ≈ 5MB, 학생 PC에 로컬 저장(중앙 저장 부담 0).
- **커버 이미지(PNG)**: 업로드한 그림 + 명패(제목·분위기·음계·악기) + ▶ 글리프를 캔버스에 합성 → PNG 다운로드.
- (보너스) **공유 링크**: 레시피를 base64로 URL에 인코딩(오디오 없음, 수 KB). 같은 사이트에서 열면 복원. 서버 불필요.

## 11. 기술 범위와 파일 구조

- **단일 정적 앱**(빌드·프레임워크 없음). 로컬 http 서버 또는 폴더 열기로 실행. (음원 fetch와 동일하게 http 권장.)
- 유지보수를 위해 plain JS를 역할별 파일로 가볍게 분리(ES 모듈 미사용, 순서 로드로 file:// 폴백 동작 유지):
  - `manifest.js` — 음원·분위기·악기·음계·버전 데이터(선생님이 음원 추가 시 여기만 수정).
  - `audio-engine.js` — Web Audio 그래프, 피치 시프트, 시김새, 오프라인 렌더링.
  - `drawing.js` — 캔버스 드로잉, 시간/음높이 매핑, 리듬 자동완성.
  - `studio.js` — 위저드 흐름, UI 렌더, 저장/내보내기 연결.
  - `index.html`, `styles.css` — 갤러리 톤으로 대폭 재작성.
- 기존 검증된 매핑/오디오 로직은 내부 재사용.

## 12. 비목표(Non-goals) / YAGNI

- 서버·DB·계정·실시간 협업 **없음**(교실용 단순함 우선, 용량/운영 부담 회피).
- 학생 간 사이트 내 직접 공유 **없음**(다운로드 제출 또는 공유 링크로 대체).
- MP3 인코딩은 초기 범위 외(WAV로 충분, 필요 시 후속). 실시간 그리며 연주도 범위 외.

## 13. 향후 추가 예정 / 열린 항목

- 선생님이 ambient/string/drone/choir/synth **패드 음원**을 추가하면 매니페스트에 연결(분류명이 현재 `배경(freesound)` 분위기명과 달라 매핑 테이블로 흡수).
- 필요 시 MP3 내보내기, 추가 음계/악기.

## 14. 완료 기준 (Acceptance Criteria)

1. 그림을 1단계에서 올리고 이후 단계에서 썸네일이 유지된다.
2. 15/30/45초 선택에 따라 팔레트 구간 수가 바뀐다.
3. 분위기 선택 시 배경 패드+효과음이 연결되고 화면 무드 색이 바뀐다.
4. 악기·음계 선택이 드로잉 선율 음색·음계에 반영된다.
5. 드로잉이 **그리는 속도와 무관**하게 가로=시간으로 매핑되고, 음높이가 선택 음계로 자동 보정되며, 4/4 리듬으로 자동완성된다.
6. 국악(기)·국악풍에서 시김새(꺾음·흘러내림·떠는음)가 청각적으로 구분된다.
7. "이 시도 저장"으로 여러 테이크를 저장·비교 재생할 수 있다(새로고침 후에도 유지).
8. 완성작을 WAV + 커버 PNG로 내보낼 수 있다.
9. 음원 파일이 없어도 합성음으로 끊김 없이 동작한다.
10. 데스크탑 브라우저에서 마우스로 전 과정이 매끄럽게 동작한다.
