# 그림 위에 선율을 긋는 메인

확인일: 2026-10-03

## 결론

메인 연출을 "붓이 畵·音을 지나며 그림과 음표를 흩뿌리는" 방식에서 **산수화 위에 금빛 선율 한 줄이 그어지고, 그 선이 음악이 되는** 방식으로 바꾼다. 화음의 실제 사용법(그림 위에 선을 그으면 가로=시간, 세로=음높이로 선율이 된다)을 문구를 늘리지 않고 장면으로 보여 주기 위해서다. 사용자는 기존 화면의 붓 움직임이 어색하고, 코드로 그린 음표·잎이 그림과 따로 논다고 지적하며 그림 소재를 엮는 방향을 제안했다.

- 배경은 새 산수화 `assets/hero/melody-landscape.webp`(1536×1024, 원본 비율 그대로 cover)이다. 선율이 지나간 자리부터 그림이 밝아지고, 마지막 긴 음이 달 옆에서 끝나면 달무리가 번진다.
- 붓 모형은 없앤다. 선은 보이지 않는 손이 긋듯 가로는 박자대로 일정하게 나아가고, 세로는 다음 음높이를 부드러운 스프링처럼 쫓는다. 짧은 음은 미끄러지듯 지나고, 긴 음은 머물며 농현처럼 떨린다. 빠르게 오르내리는 곳은 가늘어진다.
- 음표는 코드 도형 대신 금박으로 그린 음표 그림 `assets/hero/gold-notes.webp`를 쓴다. 음 길이에 맞춰 8분음표·4분음표(3박은 점 추가)·2분음표를 고르고, 선에서 떠올라 그 위에 머문다.
- 떠다니던 畵·音 글자는 제목 옆 붉은 낙관(畵音)으로 바꾼다. 같은 두 글자이므로 보이는 문구는 늘지 않는다.
- 하단에 선율 듣기 버튼(아이콘)을 둔다. 누르면 선이 다시 그어지며 스튜디오와 같은 대금 원음으로 그 선율이 연주된다. 선과 소리는 `index.html` 안의 선율 표 `MELODY` 하나를 함께 따른다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 벡터 붓이 경로를 따라 이동하고 9가닥 선·코드 음표가 꼬임 | 붓이 스티커처럼 미끄러지고 도형 음표가 그림과 따로 논다는 피드백으로 폐기 |
| 빠른 스프링(5.2 Hz)으로 음높이를 정확히 따라가는 선 | 계단식 그래프처럼 보여 기계적. 비교 렌더 후 제외 |
| 부드러운 스프링(2.3 Hz, 감쇠 0.84)으로 음높이를 쫓는 선 | 채택. 짧은 음은 노래하듯 지나고 긴 음은 머물러 사람 손의 선율로 읽힘 |
| 음표 머리를 선 위에 꽂기 | 핀처럼 보여 어수선함. 선 위로 떠오르게 변경 |
| 소리 자동 재생 | 브라우저 정책상 불가하고 교실에서 갑작스러움. 버튼으로만 재생 |

## 적용 방향

- `index.html`은 계속 자족형(inline CSS·SVG·Canvas·classic script)이며 앱 모듈을 읽지 않는다. 그래서 대금 원음의 측정 음높이(`js/sample-calibration.js`)와 음별 게인(`js/audio-engine.js`의 `NOTE_MELODY_OUTPUT_GAINS.daegeum`)을 `TAKES` 상수로 옮겨 쓴다. 앱에서 대금을 다시 측정하면 이 값도 함께 갱신한다.
- 두 번째 음부터는 스튜디오 펜 소리처럼 원음의 숨으로 음이 올라오는 앞부분(최대 0.45초)을 건너뛴다. 대금 솔(G4)은 앞 0.4초 동안 약 −18 cent에서 올라오기 때문이다. 페이지 코드를 오프라인으로 렌더해 재면 모든 음이 목표 ±8 cent 안이고 피크는 약 −11 dBFS다. 출력은 스튜디오와 같은 −3 dBFS 브릭월 리미터를 거친다.
- 선은 0.45초에 시작해 4.4초 동안 그린다. 제목·문구·버튼은 기존과 같은 5.05초부터 나타나고 낙관은 6.45초에 찍힌다. 완성 뒤에는 12초마다 붓끝과 같은 빛이 선을 따라 지나가며 음표를 차례로 밝힌다.
- 선율 듣기는 누르는 즉시 선을 다시 그리고, 음원이 준비되면 그 위치에서 소리가 합류한다. 음원을 받지 못하면 선만 다시 그린다. 움직임을 멈췄거나 움직임 줄이기 설정이면 선은 두고 소리만 낸다.
- 움직임 줄이기 설정, JavaScript·Canvas 미지원 시 완성된 화면을 바로 보여 준다. 탭이 숨겨지면 프레임과 소리를 멈추고, 완성 뒤 빛이 지나가지 않는 동안에는 다시 그리지 않는다.
- 기존 `shareChannel`·`channel` 쿼리의 갤러리 이동은 유지한다.
- 1920×1080, 1600×900, 1440×900, 1366×768, 1280×720, 2560×1080에서 제목·선율·달이 겹치지 않음을 확인했다.

## 소재 제작

배경과 음표는 Codex 내장 이미지 생성으로 만들고 ffmpeg로 WebP(배경 quality 82, 음표 quality 90 + 알파)로 변환했다. 음표는 검은 바탕 생성본에서 밝기로 알파를 뽑아 쓰는 5종만 잘라 붙였다. 프롬프트는 `../specs/2026-10-03-melody-landscape-prompt.txt`에 기록한다. 낙관 글자는 [Noto Serif KR](https://github.com/google/fonts/tree/main/ofl/notoserifkr)(OFL) Black의 畵·音 윤곽을 SVG 경로로 옮긴 것이다.

`2026-10-03-brush-to-melody-landing.md`의 붓 연출과 `brush-melody.webp` 배경은 이 결정으로 대체된다. 중앙 문구 구성·서체·등장 시각(`2026-10-03-landing-intro-hierarchy.md`, `2026-10-03-flowing-landing-copy.md`)은 그대로 따른다.
