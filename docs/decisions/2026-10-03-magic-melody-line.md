# 마법의 선율: 도화지 선을 빛나는 선율로

확인일: 2026-10-03

## 결론

3단계 도화지의 선을 "마법의 붓이 남긴 선율"로 그린다.
- 한 경로를 빛무리·빛·선 세 겹으로 칠하고, 위쪽에 가는 윤기를 얹는다. 점 사이는 곡선으로 부드럽게 잇는다.
- 선을 따라 금빛 반짝임을 드문드문 박는다.
- 선율의 봉우리에는 음표(♪·♫)가 떠오른다.

선 위에 음마다 동그란 빛 구슬을 다는 방식도 해 봤다. 하지만 동그라미가 줄지어 지저분해 보여서 넣지 않는다.

저장 좌표·레시피·소리는 바뀌지 않는다. 장식은 모두 결정적이라, 다시 그려도 깜빡이지 않고 내보낸 PNG·영상에도 그대로 담긴다.

`2026-10-03-instrument-brush-drawing.md`의 "외곽과 중심을 한 번씩 렌더"는 이 문서의 세 겹·윤기 렌더로 바뀐다. 한 경로를 한 번에 이어 그려 round cap 겹침을 막는 원칙은 그대로다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 외곽+중심 두 겹 선(이전) | 깔끔하지만 마법의 악기 붓·음악과 이어지지 않음 |
| 보정 음 막대를 다시 표시 | 그림에 없는 직선이 겹쳐 복잡함(이전 결정 유지) |
| 오선(다섯 줄) 리본으로 그리기 | 음높이 칸의 가로선과 겹쳐 읽기 어려움 |
| 음이 시작되는 자리마다 빛 구슬(첫 판) | 선 위에 동그라미가 줄지어 지저분하고 선율의 흐름을 끊음. 걷어냄 |
| 반짝임을 매 프레임 무작위로 | 다시 그릴 때마다 깜빡이고 내보낼 때마다 그림이 달라짐 |
| 빛나는 선 + 곡선 연결 + 드문 금빛 반짝임 + 봉우리 음표 | 채택. 선은 깨끗하게 흐르고 음악 느낌은 떠오르는 음표가 맡음 |

## 적용 방향

- **선:** 빛무리(18px·7%)·빛(10px·16%)·선(5.6px·92%) 세 겹을 같은 경로로 칠하고, 1.3px 위에 흰 윤기(1.4px·55%)를 그린다. 점 사이 가운데를 지나는 2차 곡선으로 잇고, 그리기 함수가 없으면 직선으로 잇는다.
- **점 하나짜리 획(탭):** 선과 같은 빛무리·빛·선 세 겹의 작은 점으로 그린다.
- **떠오르는 음표:**
  - 음 계산(`compute`) 뒤의 `notes`로 자리를 정한다. 획마다 첫 음에 띄우고, 그 뒤로는 2.2초 이상 지난 봉우리(앞뒤 음보다 높은 음)나 4.8초 이상 빈 자리에서 ♪와 ♫를 번갈아 띄운다.
  - 음표는 그 시각의 선 높이에서 16px 위에 둔다.
  - 지우개로 긋는 동안(획 번호가 바뀌는 중)과 리듬형에서는 그리지 않는다.
- **금빛 반짝임:** 선을 따라 약 96px마다 선 양옆에 번갈아 박는다. 크기·거리는 획 번호와 순서로 정해 매번 같다.
- **숨긴 획:** 국악 축에서 숨기는 서양 획은 장식도 함께 숨긴다.
- **성능:** 30초를 채운 획 4개(점 12,000개)를 통째로 다시 그리는 데 구슬이 있을 때도 약 2.3ms였다(헤드리스 Chrome, GPU). 구슬을 뺀 지금은 그보다 가볍다.
- **범위 밖:** 시도 썸네일(`takes.js`)과 화음 갤러리의 대체 그림(`channel.js`)은 이번에 바꾸지 않았다.
- **확인 방법:**
  - `test/drawing-render.test.js`: 세 겹·윤기, 곡선 연결, 선 위 원 없음, 첫 음 위 음표 위치, 다시 그려도 같음, 지우는 중·리듬형 제외
  - 실제 브라우저: 서양·국악 축에서 그린 뒤의 모습 캡처
