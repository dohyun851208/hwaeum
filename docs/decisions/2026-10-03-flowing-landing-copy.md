# 중앙 문구의 서체와 이어지는 등장

확인일: 2026-10-03

## 결론

`2026-10-03-landing-intro-hierarchy.md`의 중앙 문구 구성은 유지하되 서체와 등장 속도를 변경한다. 제목 `화음`에는 연성체를 쓰고, `그림에 선율을 더하다`와 `입장하기`는 읽기 편한 기본 고딕체를 쓴다. 세 요소의 등장 구간을 겹쳐 하나의 흐름으로 이어지게 한다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 모든 문구에 같은 붓글씨 | 사용자 피드백에 따라 변경 |
| 제목에 손글씨, 설명과 버튼에 고딕체 | 채택. 제목의 개성과 짧은 문구의 가독성을 함께 유지 |
| 각 요소를 짧게 순서대로 표시 | 분리되어 나타나는 느낌을 줄이기 위해 변경 |
| 느린 드러남과 겹치는 등장 구간 | 채택. 제목에서 문구와 버튼으로 자연스럽게 연결 |

## 적용 방향

- 제목은 5.05초부터 2.1초, 문구는 5.7초부터 1.9초, 버튼은 6.3초부터 1.5초 동안 나타난다.
- 제목과 문구의 마스크·흐림·투명도를 함께 바꾼다. 기존 일시정지·다시 보기 시계를 공유한다.
- 움직임 줄이기, JavaScript·Canvas 미지원 시 완성된 화면을 즉시 표시한다.
- 연성체 `화음` 부분집합을 `assets/fonts/landing-title.ttf`로 보관한다. 출처는 [Google Fonts 원본 정보](https://github.com/google/fonts/blob/main/ofl/yeonsung/METADATA.pb), 라이선스는 `assets/fonts/OFL-YeonSung.txt`에 보관한다.
- 내부 선율 그리기는 사용자가 기존 배치 유지를 명시했으므로 도구 배치와 화면 색상을 유지하고, 악기 커서·반짝임·연속 획 렌더만 적용한다.
