# 메인 문구를 입장 버튼 하나로 합침

확인일: 2026-10-03

## 결론

메인 화면의 보이는 문구를 **화음 / 그림에 선율을 더하다 / 입장하기** 세 줄에서 **화음 / [내 그림에 선율 더하기 →]** 두 요소로 줄인다. 사용자가 문구를 더 줄이고 싶어 했고, "그림에 선율을 더하다"를 뺄지 고민했으며, "입장하기"도 더 나은 말이 있으면 바꿔도 된다고 했다. 연출(수묵화가 선율로 채색됨)이 설명을 맡게 되었으므로, 설명 한 줄은 빼고 그 뜻을 버튼의 행동 문구로 옮긴다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 세 줄 유지 | 연출과 설명이 같은 말을 반복해 화면이 무거움 |
| 설명만 빼고 "입장하기" 유지 | 가장 간결하지만 무엇을 하는 곳인지 말로는 드러나지 않고, "입장하기"는 어디로 들어가는지 알려 주지 않음 |
| 설명을 빼고 버튼을 "내 그림에 선율 더하기"로 | 채택. 한 줄이 줄어도 뜻은 남고, 브랜드 문장이 방문자가 할 행동이 됨. 스튜디오의 "선율 그리기" 단계와 낱말이 이어짐 |
| 버튼을 "그림으로 음악 만들기"로 | 더 쉬운 낱말이지만 화음 고유의 표현(선율·더하다)이 사라짐 |

## 적용 방향

- 제목이 5.05초부터 2.1초 동안, 버튼이 0.9초 뒤부터 1.6초 동안 이어서 나타난다. 낙관은 그대로 6.45초에 찍힌다. 제목 아래 간격은 24px에서 30px로 넓혔다.
- "그림에 선율을 더하다"는 브라우저 탭 제목과 검색 설명(`<title>`, `meta description`)에 남긴다.
- `test/user-facing-copy.test.js`가 버튼 문구를 고정한다.
- `2026-10-03-landing-intro-hierarchy.md`·`2026-10-03-flowing-landing-copy.md`의 세 요소 순서는 이 결정으로 두 요소가 된다.
