# 선율이 수묵화를 채색해 완성하는 메인

확인일: 2026-10-03

## 결론

`2026-10-03-picture-melody-landing.md`의 메인은 그림이 왼쪽부터 밝아지고 그 위로 선율과 음표가 지나갔다. 사용자는 "소리 음표만 선율에 맞춰 지나간다는 느낌"이라며, 선율과 그림이 **조화롭게 함께 완성되는 느낌**을 원했다. 또 "왜 소리가 안 나는지" 물었다.

- 그림은 먹색 수묵화로 시작한다. 선율의 음 하나하나가 그 자리에 색을 떨어뜨리고, 그 색이 수채화처럼 번져 산·안개·매화가 채색된다. 마지막 긴 음에서 달이 밝아지며 담채화가 완성된다. 소리가 곧 색이 되는 구조다.
- 음표는 울리는 순간 빛나며 떠오르고, 색이 번지는 동안 금박처럼 가라앉는다(불투명도 55%, 빛 25%). 선율 선도 다 그은 뒤에는 빛을 줄여 그림 위의 금니처럼 남긴다.
- 실제 크롬 창에서 재 보니 첫 클릭 전에는 오디오가 `suspended`였다. 코드 오류가 아니라 자동 재생 차단이었고, 이를 알려 주는 단서가 부족했다. 또 중간에 누르면 선율 끝부분만 들렸다. 그래서 선율이 0.6초 넘게 진행된 뒤 처음 누르면 그림을 먹색으로 되돌리고 처음부터 소리와 함께 채색한다. 소리 스위치의 안내 빛은 20초까지 둔다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 왼쪽부터 밝기가 걷히고 그 위로 음표가 지나감(이전) | 선율과 그림의 인과가 약해 음표만 지나가는 느낌 |
| 음마다 그 자리에서 수채 번짐으로 채색 | 채택. 소리가 날 때 색이 생겨 그림과 선율이 함께 완성됨 |
| 하늘까지 먹→채색 전환 | 먹 판과 채색 판의 하늘 색이 달라 하늘에 큰 번짐 경계가 생김. 빈 종이(하늘)는 처음부터 채색 판을 보임 |
| 첫 클릭 때 진행 중인 위치로 합류 | 선율 끝부분만 들려 소리가 제대로 안 난다는 인상. 시작 0.6초 이후면 처음부터 다시 그림 |

## 적용 방향

- 먹 판은 같은 그림 파일에 CSS `grayscale(1) brightness(.8)`을 건다. 채색은 캔버스가 그림 원본을 번짐 마스크로 오려 그리고, 끝나면 CSS 채색 이미지(`.is-lit`)로 넘긴 뒤 캔버스 계산을 멈춘다.
- 번짐 마스크는 그림의 1/8 크기(192×128)로 매 프레임 계산해 부드럽게 확대한다. 값 노이즈가 가장자리를 종이 결처럼 흔든다. 음이 길수록 넓게 번지고(반지름 150+55×길이), 첫 음은 매화 쪽을, 마지막 음은 달 쪽을 적신다. 마지막 음 뒤 1.7초 동안 나머지 종이도 채색된다. 인트로 동안 50 ms를 넘는 작업은 없었다.
- 다시 그릴 때는 채색이 0.65초에 먹색으로 돌아갔다가 다시 번진다. 제목·문구는 그대로 둔다.
- 스크립트가 시작되지 못하면 12초 뒤 CSS만으로 채색 그림·제목·버튼이 나타난다. 시작된 뒤 멈췄다면 그림은 먹색과 부분 채색 상태로 남고, 제목·버튼은 같은 안전장치로 나타난다.
