# 고르게 이어지지 않는 서양 악기 녹음을 칸 단위로 교체한다

확인일: 2026-10-03 · 선행: [첼로 맨 아래 솔 테이크 고정](2026-10-02-cello-lowest-g-take.md)

> 갱신(2026-10-03): 첼로 아래쪽 파의 fortissimo는 원음이 너무 커서 같은 날 음량 전수 점검에서 piano로 바꿨다
> → [음량 전수 점검](2026-10-03-loudness-audit.md)

## 결론

지속음 160칸을 같은 기준으로 검사하고, 필하모니아 라이브러리에서 **확실히 나은 녹음이 있는 서양 악기 16칸만** 바꿨다
(첼로 2·바이올린 3·오보에 11). 같은 음의 다른 테이크를 먼저 찾고, 없으면 반음 옆의 고른 녹음을 빌린다(기존 `SAMPLE_OVERRIDES` 방식).
모든 녹음을 한꺼번에 바꾸지 않는다. 세기가 다른 녹음이 섞이면 같은 악기 안에서 밝기·크기가 들쭉날쭉해지기 때문이다.

오보에는 칸을 하나 바꿀 때마다 악기 평균이 움직여, 보정 한도에 걸린 다른 칸이 작아졌다
(아래쪽 솔·시·도를 키우자 악기 게인이 내려가 위쪽 레가 기준보다 2 dB 작아지는 식).
그래서 오보에는 한 칸씩 고치지 않고 15칸을 한꺼번에 재서, 반복이 짧거나 재생 출렁임이 3 dB 이상이거나
음별 보정 한도에 걸려 작은 칸을 모두 바꿨다.
보정 후 오보에 안의 음량 차이가 5.7 dB에서 1.4 dB로 줄었다.

| 칸 | 바꾼 녹음 | 효과 |
| --- | --- | --- |
| 첼로 아래쪽 레 | 도#(C#3 forte) 빌려 반음 올림 | 출렁임 4.1 → 1.1 dB, 약해짐 2.4 → 0.6 dB |
| 첼로 아래쪽 파 | 같은 음 fortissimo | 약해짐 4.7 → 1.1 dB, 출렁임 4.3 → 2.4 dB |
| 바이올린 아래쪽 라 | 라#(A#3) 빌려 반음 내림 | 반복 0.55 → 1.36초, 출렁임 7.5 → 2.1 dB |
| 바이올린 위쪽 시 | 같은 음 fortissimo | 반복 0.79 → 1.27초, 출렁임 4.8 → 1.3 dB |
| 바이올린 위쪽 도 | 도#(C#5) 빌려 반음 내림 | 약해짐 3.9 → 1.0 dB |
| 오보에 아래쪽 솔 | 같은 음 forte | 2.5 dB 작던 소리가 다른 칸과 같아짐, 출렁임 1.5 → 0.8 dB |

| 오보에 아래쪽 미 | 파(F5 forte) 빌려 반음 내림 | 반복 0.87 → 1.21초, 출렁임 2.6 → 1.0 dB |

| 오보에 위쪽 시 | 도(C6 forte) 빌려 반음 내림 | 출렁임 4.9 → 2.1 dB |

| 오보에 위쪽 레 | 같은 음 fortissimo | 출렁임 4.3 → 2.3 dB |

| 오보에 위쪽 파 | 같은 음 piano | 출렁임 4.2 → 1.8 dB |

- 출렁임: 앱이 재생하는 그대로 4.5초 길게 그린 소리를 만들어, 50 ms 크기의 상위 5%와 하위 5% 차이를 쟀다(`output/take-compare` 비교 페이지와 같은 값).
- 반복: 엔진이 되풀이하는 안정 구간 길이. 약해짐: 녹음의 센 부분보다 반복 구간이 작은 정도.
- 오보에 아래쪽 도는 같은 음 forte·fortissimo가 오히려 더 출렁여서(3.8·2.8 dB) 반음 위를 빌렸다.

## 검사와 비교

검사 기준(엔진의 `findStableLoopRegion` → `levelSustainSupport` → `sustainLoopFrames` 경로):
세게 시작했다 약해짐(강한 부분 대비 반복 구간 3 dB 초과), 반복 구간 0.9초 미만, 반복 구간 안 출렁임 5 dB 이상.
첼로 맨 아래 솔을 뺀 서양 22칸이 해당했다. 국악 3칸(해금 위쪽 솔·도, 대금 맨 위 미, 약해짐 3.1~3.8 dB)은 국립국악원 녹음이라 이 라이브러리에 대체 녹음이 없다.

후보는 같은 라이브러리에서 받았다: 첼로·더블베이스·플루트·오보에는 공개 미러
[skratchdot/philharmonia-samples](https://github.com/skratchdot/philharmonia-samples/),
바이올린·비올라는 [Internet Archive](https://archive.org/details/philharmonicorchestrasamples)의 악기별 묶음.
같은 테이크를 측정값으로 대조해 출처를 확인했고(일부 기존 파일은 6월에 96 kb/s로 다시 인코딩돼 바이트는 다르다),
새 파일은 재인코딩 없이 원본 그대로 복사했다.

채택 조건: 약해짐 ≤ 2 dB, 반복 ≥ 1.0초(출렁임을 크게 줄이면 0.9초 이상 허용), 발음 시작 ≤ 0.35초, 음정 ±40센트·흔들림 60센트 이내,
**음별 보정 ±3 dB로 악기 기준 크기에 닿는 음량**. 개선 조건은 칸의 문제마다 약해짐 ≤ 2 dB, 반복 +0.2초, 출렁임 −2 dB이고,
반음 빌리기는 음색 손실이 있어 −2.5 dB·+0.3초·출렁임 ≤ 1.5 dB로 더 엄격하게 본다.

처음에는 음량 조건을 "기존 녹음과 ±4 dB 이내"로 걸렀다. 그런데 기존 녹음이 이미 +3 dB 보정 한도에 걸려 작던 칸은
오히려 더 큰 녹음이 필요해서, 이 조건이 좋은 후보를 막았다. 오보에 위쪽 시가 다른 음보다 작게 들린다는 청취 확인
(빌려 온 도 녹음이 mezzo-forte라 한도에 걸린 채 기준보다 2.9 dB 작았다)으로 발견해, 기준 크기를 잣대로 고쳤다.

| 판단 | 칸 |
| --- | --- |
| 교체(위 16칸) | 첼로 레·파, 바이올린 라·시·도, 오보에 아래쪽 솔·시·도·미·파, 위쪽 라·시·도·레·미·파 |
| 더 나은 녹음은 있지만 보류 | 플루트 아래쪽 솔: 솔# 녹음이 더 고르지만 2.7 dB 작아 이미 작은 저음이 기준보다 5.2 dB 작아진다 |
| 여리게 녹음된 긴 테이크만 있음(9~12 dB 작음) | 플루트 레·시·도, 비올라 미 |
| 조건을 넘는 녹음이 없음 | 첼로 솔·위쪽 레, 더블베이스 도, 플루트 파, 비올라 레, 바이올린 솔·라·레·미 |

오보에 밖의 칸은 고친 음량 조건으로 아직 다시 검사하지 않았다. 보정 한도에 걸려 기준과 2 dB 넘게 다른 칸이
서양 악기에 25칸 남아 있다(플루트 11, 프렌치호른 5, 첼로 5, 바이올린 2, 비올라 1, 더블베이스 1.
첼로 맨 아래 솔·아래쪽 파는 센 녹음이라 +2.8~2.9 dB로 큰 쪽이다).

## 적용 방향

- `tools/curate-western-samples.py`: `SAMPLE_OVERRIDES`에 6칸을 더하고(첼로 레, 바이올린 라·도, 오보에 아래쪽 도·미, 위쪽 시)
  오보에 위쪽 미의 파 빌리기는 뺐다. `TAKE_OVERRIDES`에는 이 문서의 11개 테이크를 고정했다
  (첼로 F3, 바이올린 B4, 오보에 G4·B4·C#5·F5·A5·C6·D6·E6·F6). 빌려 오는 음에 고정 테이크가 있으면 그 파일을 쓰므로
  두 칸이 같은 파일을 덮어쓰지 않는다(오보에 도#·도, 파·미, 도·시). 원본 큐레이션을 다시 실행해도 같은 결과가 나온다.
- 빌려 쓰게 된 칸의 원래 파일은 기존 관례대로 지우지 않는다(첼로 D3, 바이올린 A3·C5, 오보에 C5·E5·B5. 오보에 E5는 악기 대표 음으로도 쓰인다).
- 조율: `measure-sustain.cjs --uncalibrated` → `calibrate-sustain.py --write`로 다시 만들었다. 바꾸지 않은 141개 파일은
  최대 3.7센트만 바뀌었다(7월 이후 음량 평탄화 변경이 반영된 값). 새 오보에 녹음은 원래 −11~+27센트 어긋나 있지만
  실제 주파수를 재서 맞추므로 정확한 음으로 난다. 비올라 두 칸의 `reviewRequired`는 유지된다.
- 음량: `npm run measure:loudness -- --notes`를 반복 실행해 수렴시켰다. 오보에 악기 게인은 커밋된 1.29에서 0.94가 됐다.
  보정 후 크기는 오보에 15칸 중 12칸이 기준과 같고(아래쪽 미·파는 −3 dB 한도에서 +0.4 dB, 바꾸지 않은 맨 위 솔은 +3 dB 한도에서 −1.0 dB),
  바이올린·첼로 레가 기준 +0.2~+0.7 dB, 센 연주 테이크(첼로 솔·파)는 +2.8~2.9 dB다. ±3 dB 한도를 넓히지 않는다.
- 측정값을 고정한 테스트(악기 게인, 빌린 칸의 음정·게인)를 새 값으로 바꾸고 새 빌림 칸을 회귀 사례에 추가했다.
  오보에 위쪽 미 테스트는 "짧은 테이크를 피해 파를 빌린다"에서 "같은 음의 긴 테이크를 쓴다"로 바꿨다.
- 확인 주의: 앱은 MP3를 캐시 표시 없이 불러온다. 로컬 서버(`python -m http.server`)는 캐시 헤더가 없어 같은 이름으로 바꾼 녹음을
  브라우저가 예전 것으로 재생할 수 있으니 시크릿 창에서 듣는다. 배포 사이트(Vercel 기본값)는 매번 새로 확인한다.
- 남은 한계(13칸)는 이 라이브러리 안에서는 더 고를 녹음이 없다. 더 바꾸려면 다른 출처의 녹음이 필요하다.
