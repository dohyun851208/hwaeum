# 해금: 울림통 공명 깎기와 짧은 미끄러짐

확인일: 2026-10-04 · 선행: [귀 기준(A-가중) 악기 크기](2026-10-03-perceived-loudness-a-weighting.md), [자연스러운 선율 전환](2026-10-02-natural-melody-transitions.md)(해금 미끄러짐 0.12·0.09초 복원)

## 결론

사용자가 해금이 "깨끗하게 안 들린다"고 했다. 원인은 셋이었다.

1. **녹음 자체의 콧소리 공명.** 기본음이 0.01~0.07(가장 큰 배음 대비)이고, 1.4~1.8 kHz 근처 배음 하나가 압도한다(G4는 4배음, D#4는 5배음, C4는 6배음, A#4는 3배음). 대금은 기본음이 1.00이다.
2. **긴 미끄러짐.** 시정수 0.12초라 0.5초짜리 음의 앞 3분의 1이 음정 사이를 미끄러진다. 음정이 맞는 시간이 11%였다(대금 68%).
3. 녹음 음높이가 G#·A#·C·C#·D#·F·G라서 라·레·미는 반음 옆 녹음을 옮긴다. 이것은 그대로 둔다.

녹음을 바꾸려고 무료 출처 셋을 모두 확인했지만 음색이 같았다. 국립국악원 디지털음원 단음 기본음계(약·중·강, 지금 앱은 '중'), 같은 사이트 확장 자료(다른 연주자 김승태, 악구 276개), 공유마당 「국악기_해금1~80」(한국저작권위원회, CC BY)이다. 왼쪽·오른쪽 채널 위상 상쇄도 아니었다(상관 +0.6~0.9). 그래서 녹음 문제가 아니라 해금 본래의 음색이다.

비교 청취 페이지(`output/haegeum-tone/`, 크기는 A-가중으로 대금에 맞춤)에서 사용자가 **③ 공명 깎기 + 미끄러짐 짧게**를 골랐다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 지금(공명 그대로, 미끄러짐 0.12초) | 가늘고 휘파람 같으며 음 앞부분이 흐림 |
| ① 미끄러짐만 짧게(0.05초) | 음이 빨리 잡히지만 휘파람 같은 음색은 그대로 |
| ② 공명만 깎기 | 2·3배음이 살아나 음색이 차지만 음 앞부분은 흐림 |
| ③ 둘 다 | 채택 |
| 다른 해금 녹음으로 교체 | 무료 출처 셋이 모두 같은 음색이라 효과 없음. 유료 샘플은 라이선스 때문에 쓸 수 없음 |

## 적용 방향

- `js/audio-engine.js`: 해금에만 peaking 필터 두 개(1450 Hz·Q 1.4·−14 dB, 1750 Hz·Q 1.6·−14 dB, `HAEGEUM_RESONANCE_CUTS`)를 국악 음색 필터(2300 Hz 저역 통과) 뒤에 이어 붙인다. `sampleToneFilters()`가 필터 목록을 만들고, 전체 재생(`connectGugakSampleTone`), 펜 소리(`_createSampleLivePreview`), 음 미리듣기(`_previewSample`)가 모두 같은 목록을 쓴다. `disconnectQuietly()`는 목록도 풀어서 끊는다.
- 음 미리듣기는 그동안 음색 필터 없이 녹음을 그대로 냈다. 해금은 공명을 깎은 만큼 게인이 커서, 빼면 이 소리만 십몇 dB 크게 난다. 그래서 다른 국악기(가야금 제외)의 음 미리듣기도 재생·펜과 같은 저역 통과 필터를 거치게 됐다.
- 미끄러짐 시정수: 전체 재생 0.12 → 0.05초, 펜 0.09 → 0.04초. 직전 음높이에서 출발하고 인위적인 꾸밈음은 없다는 기존 원칙은 그대로다.
- `tools/measure-instrument-loudness.cjs`도 같은 공명 깎기를 거쳐 잰다(`HAEGEUM_TONE_FILTER`). 해금의 음별 보정을 다시 계산했다(깎은 뒤 음 사이 차이 15.6 dB → ±12 dB 안에서 0). 악기 게인은 0.29 → 2.00(+16.8 dB)이다. 공명이 해금 소리 에너지의 대부분이라 깎은 만큼 다시 키운다. 다른 악기의 값은 바뀌지 않았다.
- 크롬 실제 재생 확인(A-가중, 바이올린 대비): 해금 재생 +0.1, 펜 +0.2, 선율 +0.6~0.7 dB. 펜 소리는 다른 악기처럼 재생보다 1.7 dB 작다. 10칸 크기 차이는 0.9 dB다. '라'의 1~6배음이 0.02·0.07·0.10·1.00·0.03·0.05에서 0.23·0.43·0.14·1.00·0.09·0.32가 됐다.
- 펜 소리 상한: "그림소리 강조"에서 해금 기준 게인 1.94(상한 4.16), 음별 보정이 가장 큰 칸(×2.54)도 4.93(상한 5.85)이다.
- 테스트: 해금만 세 경로 모두에서 공명 필터 두 개를 쓰고 대금은 쓰지 않는지 확인하는 테스트를 더했다. 미끄러짐 시정수, 해금 게인, 해금 높은 미 음별 보정 기대값을 바꿨고, 가짜 Web Audio 필터에 `gain` 값을 넣었다.
- 실제 해금보다 덜 해금다워지는 것은 감수한다. 2단계 감상 연주곡은 원래 해금 녹음 그대로라서, 진짜 해금 소리를 듣는 활동은 그대로 할 수 있다.
