# 화음 갤러리 작품 벽을 예전 전시실로

확인일: 2026-10-03

## 결론

`2026-10-03-ink-gallery-renewal.md`의 작품 벽(한눈에 보기·커버플로우)을 일주일 전(8월 18일 배포본) 전시실로 되돌린다. 전시실 사진 벽, 나무 선반, 커버플로우 무대, 정사각 표지, 얇은 금빛 선, 표지 위 이름표 띠가 다시 쓰인다. 머리줄·글꼴·입구와 잠김 화면(먹빛 로비)·작품 보기 창·메뉴는 리뉴얼을 유지한다.

사용자 판단: 커버플로우는 모든 표지를 강제로 정사각형으로 맞출 때 연속성과 통일감이 살아난다. 예전 버전은 주변까지 정말 전시관·박물관에 있는 느낌이었는데, 리뉴얼은 디지털 앨범 같다. 테두리(10px 크림 매트)는 굵을 필요 없이 깔끔한 편이 낫다.

## 비교

같은 가짜 작품 11개(가로·세로·정사각 그림 섞음)를 일주일 전 배포본, 현재 운영본, 시안에 넣어 1600×900으로 비교했다.

| 방식 | 판단 |
| --- | --- |
| 리뉴얼 유지(먹빛 벽 + 크림 매트 액자 + 아래 이름표) | 깔끔하지만 디지털 앨범 같고, 커버플로우 위쪽 절반이 빈 어둠 |
| 그림 비율대로 액자 | 잘림은 없어지지만 커버플로우의 통일감이 깨지고 전시관 느낌은 여전히 없음 |
| 정사각 액자 + 넓은 매트 | 그림은 다 보이지만 매트가 그림보다 밝고 넓음 |
| 갤러리 전체를 예전으로 | 입구 화면 가운데 맞이, 글꼴 통일, 14px 바닥을 잃음 |
| 예전 전시실 + 리뉴얼 머리줄·글꼴·로비 | 채택. 비교 화면에서 예전과 다른 점은 머리줄 색·글꼴과 이름표 글자 크기뿐 |

## 적용 방향

- `styles.css`의 `@gallery-renewal-2026-10` 구간에서 "작품 벽"과 "커버플로우" 구간을 지웠다. 덮어쓰기 구간이라 그 아래 예전 규칙이 다시 드러난다. 쓰이지 않게 된 `--g-mat` 토큰도 지웠다.
- 먹빛 벽·한지 결·흐린 산수화(`::before`·`::after`)는 `body.channel-body:not([data-gallery-state="open"])`, 곧 로비(입구·불러오는 중·잠김·빈 전시)에만 둔다. 작품이 열리면 예전 `.channel-body` 배경(전시실 사진)이 나온다. 지운 작품 벽 구간이 하던 일 중 로비의 예전 벽 세로 금선(`.channel-library`) 지우기는 따로 남겼다.
- 이름표: 리뉴얼 때 나눈 제목·작곡가 요소(`createAlbumCard()`, `test/cover-ui.test.js`가 고정)는 그대로 두고 CSS가 괄호를 붙여 「제목 (작곡가)」 한 줄로 보인다. 제목·작곡가는 15px 600, 단어는 14px 600이다(예전 단어는 약 11.8px로 14px 바닥 아래였다).
- 정사각 표지라 길쭉한 그림은 위아래나 양옆이 잘린다. 통일감을 위해 감수한다.
- 전시실 사진 속 액자들이 학생 작품과 겨룬다는 리뉴얼의 지적도 감수한다. 사용자는 전시관에 있는 느낌을 더 중요하게 봤다.
