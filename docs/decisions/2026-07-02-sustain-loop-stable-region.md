# 지속음 루프 구간을 포락선 기반 안정 구간으로 (파일럿: 더블베이스)

확인일: 2026-07-02

## 결론

드로잉에서 길게 끈 음을 지속음으로 만드는 샘플 루프 구간을, 고정 비율(파일의 28~78%)이 아니라
**샘플 RMS 포락선에서 검출한 "가장 긴 평탄 구간"**으로 잡는다.
우선 측정에서 맥동("두두두두")이 가장 심했던 **더블베이스에만** 적용하고(파일럿), 귀 검증 후 명단을 넓힌다.

## 비교

410개 선율 샘플을 ffmpeg 50ms RMS로 측정. "이음매 음량차" = 루프 시작·끝 지점의 RMS 차이 —
클수록 루프가 돌 때마다 음량이 출렁여 맥동으로 들린다. 원인: 필하모니아 현악 샘플은 파일 안에
음의 끝(릴리스·감쇠)이 포함되어 있어, 78% 지점이 감쇠 꼬리에 걸린다. 관악·국악 관악은 평탄해서 문제 없음.

| 방식 | 장점 | 단점 | 판단 |
| --- | --- | --- | --- |
| 고정 비율 28~78% (기존) | 단순, PCM 분석 불필요 | 감쇠 포함 샘플에서 꼬리를 물고 돎 — 더블베이스 이음매 차 평균 15.3dB·최대 32.7dB | 폴백으로만 유지 |
| 음마다 수동 지정 (`sustainLoopHint`) | 정확 | 410개 파일에 반복 불가(바이올린 G3 한 음만 지정된 상태였음) | 오버라이드로만 유지 |
| 포락선 기반 자동 검출 | 실측 더블베이스 44/44 파일에서 루프 0.9~1.4초 + 이음매 차 대부분 ≤4dB | 분석 실패 가능 → 폴백 필요 | 채택(파일럿) |

⚠ 이음매 음량만 맞추면 안 된다(1차 시도의 교훈): 완전히 평탄해도 루프가 짧으면(1초 미만)
소리 질감 자체가 빠르게 반복돼 스터터("두두두두")로 들린다. **루프 길이가 우선**이고,
이음매 차이는 긴 크로스페이드로 흡수한다. (비교 기준: 첼로 최저 솔 = 1.15초 루프가 자연스럽게 들림)

## 적용 방향

- `js/music-core.js`의 `findStableLoopRegion(channelData, sampleRate, offset, duration, options)` —
  순수 함수(50ms RMS 창). 평탄 밴드를 3 → 4.5 → 6 → 8dB로 넓혀 가며 **목표 길이 0.9초 이상**의
  구간을 찾을 때까지 시도, 못 넘으면 찾은 것 중 가장 긴 구간(최소 0.3초). 단위 테스트 `test/sustain-loop-region.test.js`.
- `js/audio-engine.js`의 `autoSustainLoopHint()` — 파일럿 명단 `SUSTAIN_AUTO_LOOP_INSTRUMENT_IDS`(현재 doubleBass).
  검출 실패·PCM 없음이면 기존 비율 방식 폴백. 자동 검출 루프는 크로스페이드를 0.16초(기존 0.08초의 2배)로
  잡아 이음매 음량·질감 차이를 흡수한다.
- 수동 `sustainLoopHint`가 있으면 그것이 우선. 가야금은 `shouldSustainSample()`에서 계속 제외(뜯는 악기).
- **루프 끝점 파형 정렬**: 위상이 어긋난 채 크로스페이드하면 간섭·상쇄로 금속성(플랜저) 이음매가
  들린다(귀 검증에서 확인, 더블베이스 맨 위 솔). 끝점을 시작점 30ms 창과 상호상관이 최대인 위치(±20ms)로
  미세 조정하고, 절대 초 힌트는 제로크로싱 재스냅을 건너뛴다(정렬 보존). 실측 44파일 상관 대부분 ≥0.9.
- **음별 음량 보정 확대**: 더블베이스는 음마다 녹음 강약 차가 커서(루프 RMS 스프레드 19.3dB,
  B2·E3가 유독 -31dB급) ±3dB 한도로는 13.3dB가 남는다. 자동 루프 파일럿 악기에 한해
  `AUTO_LOOP_NOTE_GAIN_LIMIT_DB = 12`(엔진·측정 도구 동일)로 넓혀 스프레드를 2.7dB까지 줄였다.
  측정 도구는 자동 루프 악기의 음량을 실제 루프 구간 RMS로 잰다(`tools/measure-instrument-loudness.cjs`).
- 귀 검증 후 확대 순서(측정 이음매 차 순): violin 11.4dB → viola 7.4 → cello 3.6 → oboe·flute 일부.
  관악(clarinet·frenchHorn)과 국악(sogeum·daegeum·haegeum·danso)은 0.6~1.6dB로 현행 유지해도 문제 없음.
