# 직접 써 보며 찾은 버그 전수조사 뒤의 설계 결정

확인일: 2026-10-07 · 선행: [효과음 도장 길이 띠](2026-10-06-effect-stamp-length-band.md), [갤러리 코드 점유](2026-06-28-channel-secondary-password.md)

## 결론

사용자가 "음악을 만들고 저장하고 내리면 표지가 목록을 덮는다"는 버그를 찾은 뒤, 학생·교사가 손으로 쓰다가 만날 수 있는 버그를
전부 찾아 달라고 했다. 실제 Chrome을 헤드리스로 몰아 1~5단계와 화음 갤러리를 여섯 갈래로 나눠 조작해 보고
(화면 7가지 크기 + Windows 배율 125·150%), 높음 11 · 중간 26 · 낮음 20여 건을 찾았다.
보안 1번(관리자 공통 코드 8624가 화면에 보이고 그 코드만으로 작품·갤러리를 지울 수 있음)은
**교실용 개방형 도구라 그대로 둔다**는 사용자 결정에 따라 손대지 않았고, 갤러리 코드를 끝없이 시도할 수 있는 것도 같은 까닭으로 두었다.
나머지는 모두 고쳤다. 고치며 정한, 되돌리기 어렵거나 다음 사람이 알아야 할 결정은 아래와 같다.

## 1. 작업을 잃지 않게

- **초기화(키보드 4)는 묻고, 되돌릴 수 있다.** 지울 것이 있을 때만 확인 창을 띄우고, 초기화 자체를 되돌리기 기록(`type: "reset"`)으로 남긴다.
  획은 캔버스 자체의 되돌리기 스냅샷(`draw.clear(true)`)에 두어 구간 길이를 바꿔도 함께 맞춰진다. Ctrl+Z(맥 ⌘+Z)도 되돌리기다.
- **저장하지 않은 바뀜은 지문으로 판단한다.** 마지막 저장·불러오기 때의 레시피 지문과 지금 지문을 견준다(`workSignature`).
  저절로 늘어나는 시도 횟수와 path는 빼고, 그림은 원본 문자열 대신 짧은 지문으로 견준다(뒤에서 압축돼도 같게).
  다른 작품을 열 때·페이지를 떠날 때(`beforeunload`) 이 지문으로 묻는다. 이미 열린 작품을 다시 누르면 다시 불러오지 않는다.
- **새 그림·초기화는 새 작품이다.** `activeTakeId`를 비워 다음 저장이 앞 작품을 덮지 않는다.
- **내 작품 저장소(`takes.js`).** 그림 data URL은 작품마다 넣지 않고 `sda.takes.pictures`에 한 번만 두고 작품은 `pictureRef`만 가진다
  (같은 그림의 여러 시도가 공간을 한 번만 쓴다). 저장이 실패하면(저장 공간 가득) 메모리를 되돌리고 `lastError`로 알린다 — 예전엔
  "저장했어요"라고 하고 새로고침하면 사라졌다. 24개 한도에서는 가장 오래된 작품을 지우지 않고 저장을 거절한다(공용 PC에서 남의 작품이 지워졌다).
  바꾸기 전에 저장소를 다시 읽어 다른 탭의 저장을 지우지 않는다. 옛 형식(그림이 레시피 안)도 그대로 읽는다.

## 2. 시간과 길이는 한 길로

- 작품 길이는 `studio-transport.js`의 `changeDuration` 하나로만 바꾼다. 선율(`draw.retimeDuration`)·도장(`retimeEffectStamps`)·
  추가 소리·재생 위치가 같은 '초'에 남는다. 2단계 카드 클릭이 `state.duration = 30`을 바로 써서 그린 선율이 늘어나던 문제를 막았다.
- 배경을 새로 고르면 처음(0초)부터, 길이는 그린 것이 다 들어가도록 `max(30초, 그린 것의 끝)`을 마디 단위로 올림한다.
  이미 고른 카드를 다시 누르면 다시 듣기만 한다.
- 구간 끝 너머로 간 도장은 지우지 않고 숨긴다(x>1). 재생 계획은 끝으로 끌어오지 않고 소리를 내지 않는다.
- 배경 시작 칸에 곡 길이를 넘는 값은 받지 않는다(끝으로 끌어오면 작품이 2.5초가 되고 뒤 선율이 숨었다).

## 3. 오디오는 저장하지 않는다 — 이름과 설정만 남기고 다시 잇는다

CLAUDE.md의 "오디오는 저장하지 않는다"를 지킨다. 그 대신
- '내가 찾은 음악'은 겹치지 않는 id(`custom-<시각>-<번호>`)를 쓴다. 페이지마다 1부터 세던 id 때문에 새로 올린 노래가 예전 작품에 붙었다.
  레시피에 `atmosphereLabel`을 남기고, 파일이 없으면 '다시 올려 주세요' 자리표시 카드(`missing: true`)와 함께 구간을 기억한다.
  같은 이름의 파일을 다시 올리면 그 자리에 이어 붙인다. 파일이 없으면 공유를 막는다.
- 추가 소리도 파일이 없으면 설정(`missing: true`, src 없음)을 레시피에 남기고, 같은 이름의 파일로 다시 잇는다.
- 10분이 넘는 음악·소리 파일은 받지 않는다(통째로 풀면 45분 → 약 1 GB). 지운 소리의 풀어 둔 버퍼는 `engine.releaseAsset`으로 비운다.

## 4. 소리

- **내보내기 녹음은 재생과 다른 AudioContext에서 한다.** 같은 컨텍스트면 녹음 중 ❚❚(suspend)가 녹음까지 멈춰 잘린 파일이 "완료"로
  저장·공유됐다. 곡 끝(`onended`)까지 담지 못하면 오류로 알린다.
- **합성음 대체 크기(`SYNTH_MELODY_TRIM_DB`).** 음원을 못 받으면 나는 합성음이 실제 음원보다 5~23 dB 컸다(작게 녹음된 음원에 맞춘
  악기 게인을 꽉 찬 파형에 곱함). 낮은·가운데·높은 음역 선율을 음원과 합성음으로 렌더해 평균 RMS를 맞춘 악기별 보정을 넣었다
  (13악기 모두 ±0.2 dB, 음역별 ±1.8 dB). 음별 보정(`NOTE_MELODY_OUTPUT_GAINS`)은 녹음 세기를 맞추는 값이라 합성음에는 쓰지 않는다.
  `INSTRUMENT_MELODY_OUTPUT_GAINS`를 바꾸면 `node tools/measure-synth-fallback.cjs`로 다시 재고 `--check`로 확인한다.
- 받기에 실패한 음원은 5초만 기억하고 다시 받는다(예전엔 새로고침 전까지 합성음).
- 시김새는 그 획을 그린 악기를 따른다(국악기를 고른 상태에서 서양 악기 줄에 붙던 것). 국악 줄이 숨은 칸을 한 번 스치는
  1/16초 빈자리는 앞 음으로 메운다.
- 일시정지 중 효과음·음 미리듣기는 멈춘 곡을 먼저 끝낸다(컨텍스트를 깨우면 멈춘 곡이 다시 흘렀다).
  재생 단추가 없는 1·2·5단계로 가면 소리를 멈추고, 스페이스는 3·4단계에서만 작품을 듣는다.

## 5. 화음 갤러리·공유

- **로컬(이 브라우저) 갤러리는 공유 API가 없을 때만**: JSON이 아닌 404·405·501 응답이나 파일(`file:`)로 연 경우.
  운영에서 연결이 끊기거나 서버가 오류를 내면 로컬로 빠지지 않고 "공유 서버에 연결하지 못했어요"를 보인다.
- **갤러리 목록은 그림을 빼고 보낸다**(`listedMeta`, `recipe.pictureOmitted`). 작품당 70~110 KB라 40~60개면 Vercel 응답 한도(4.5 MB)에
  닿았다. 카드·크게 보기는 표지 파일을 쓰고, "스튜디오에서 보기"만 `GET /api/share/work`로 전체 레시피를 읽는다. 작품 정보는 8개씩 함께 읽는다.
- **같은 작품을 다시 공유하면 바꾼다.** 작품 기록에 갤러리별 공유 작품 번호(`take.shared`)를 남기고, 다시 공유할 때 `replaceWorkId`를
  보낸다. 서버·로컬 모두 소유자(`ownerHash`·`ownerId`)가 같을 때만 예전 것을 지운다.
- 갤러리 코드는 30초 음악 압축 전에 먼저 확인하고, 공유에 성공한 뒤에만 기억한다. 기억한 코드는 8시간 뒤 잊는다(공용 PC).
  공유 창은 번호 칸에 초점을 둔다.
- 갤러리 이름 가리기는 학년·반·번호 표시를 남기고 이름 글자 전체를 한 이름으로 가린다("김 하 음" → "김 * 음").
  복사본("스튜디오에서 보기")에는 친구 이름·감상 메모를 가져가지 않는다.

## 6. 화면

- 3단계 안내는 도화지 아래쪽에 잠깐 떴다 사라지는 알림(`#drawingStatus`)으로, 2단계 악기 안내는 악기 카드 아래 줄(`#instrumentStatus`)로 보낸다
  (`studio.js`의 `say`). 예전엔 모두 4단계 칸에 써서 3단계에서 보이지 않았다.
- 4단계는 어느 폭에서나 두 칸(표지 | 설명·그 아래 내 작품). 세 칸은 1024 폭에서 넘쳤다. 갤러리 최소 폭 960px, 1100px 이하에서 단계 탭 글자 14px.
- 읽는 글자 14px 바닥을 추가 소리 카드·내 작품 카드·안내 줄·출처 줄까지 지킨다.
