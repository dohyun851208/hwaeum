# 첼로 맨 아래 솔은 같은 음의 fortissimo 테이크로 고정한다

확인일: 2026-10-02

> 갱신(2026-10-03): 이 fortissimo 테이크는 고르지만 원음이 다른 칸보다 8.7 dB 커서 첼로 게인을 끌어내렸다.
> 아래 "대안"(F#2 forte 빌리기)으로 바꿨다 → [음량 전수 점검](2026-10-03-loudness-audit.md)

## 결론

첼로 맨 아래 솔(화면 55 → 재생 midi 43, `cello_G2.mp3`)의 원본 테이크를
`cello_G2_15_forte_arco-normal.mp3`에서 같은 음의 **`cello_G2_15_fortissimo_arco-normal.mp3`**로 바꾼다.
`tools/curate-western-samples.py`의 `TAKE_OVERRIDES`에 고정해 원본 큐레이션을 다시 실행해도 유지한다.
음높이를 옮기지 않으므로 `cents`가 없고, 맵 항목과 파일 이름은 그대로다.

## 증상과 원인

증상: 3단계에서 첼로로 가장 아래 솔을 그리면 다른 음과 달리 지속음이 되지 않고 뚝 끊기듯 들린다.

엔진이 아니라 테이크가 원인이다. 기존 forte 테이크는 활을 0.7초만 힘 있게 긋고 이후 약 8 dB 약해지며,
약해진 부분이 초당 5번 ±3 dB로 출렁인다. 안정 구간 검출은 1.02초 이상의 구간을 찾으므로 강한 앞부분이 아니라
약한 꼬리(1.38~2.47초)를 반복 구간으로 골랐다. 그래서 전체 재생에서는 첫 1초가 이후보다 6.9 dB 커서
"세게 나왔다가 뚝 떨어지는" 소리가 났다. 이웃 테이크(F#2·G#2·A2 forte)는 1.6~1.9초 동안 고르게 유지된다.

같은 음 테이크 비교(48 kHz, 엔진의 `findStableLoopRegion`→`levelSustainSupport`→`sustainLoopFrames` 경로):

| G2 테이크 | 강한 부분 3 dB 이내 유지 | 반복 구간 | 앞부분 대비 반복 구간 | 반복 구간 안 변화 |
| --- | ---: | ---: | ---: | ---: |
| forte (기존) | 0.70초 | 1.09초(약한 꼬리) | 7.9 dB | 5.4 dB |
| **fortissimo (채택)** | **1.80초** | **1.53초** | **0.4 dB** | **0.9 dB** |
| mezzo-piano | 0.90초 | 0.99초 | 9.2 dB | 4.5 dB |
| pianissimo | 0.55초 | 1.01초 | 11.4 dB | 2.9 dB |

이 PC에는 원본 아카이브가 없어, 공개 미러 [skratchdot/philharmonia-samples](https://github.com/skratchdot/philharmonia-samples/)에서
같은 라이브러리의 cello 테이크를 받았다. 미러의 `cello_G2_15_forte_arco-normal.mp3`는 저장소의 기존 `cello_G2.mp3`와
바이트 단위로 같아 출처가 같음을 확인했다. 새 파일도 재인코딩 없이 그대로 복사했다(도구의 `shutil.copy2`와 같은 결과).

## 비교

| 방법 | 장점 | 단점 | 판단 |
| --- | --- | --- | --- |
| 같은 음 fortissimo 테이크 | 원래 음높이 그대로, 1.8초 고르게 유지 | 이웃(forte)보다 한 단계 센 연주라 조금 밝고, ±3 dB 보정 한도 때문에 첼로 기준보다 약 3 dB 큼 | **채택** |
| 옆 음 F#2(forte) 빌려 반음 올림 | 이웃과 같은 세기, 고르게 유지 | 반음 이동으로 음색이 약간 바뀜 | 대안(청감상 더 나으면 `SAMPLE_OVERRIDES`로 전환) |
| forte 유지 + 엔진 보정 | — | 강→약 모양 자체가 남고, 음량 보정 확대는 규칙 위반 | 미채택 |

## 적용 방향

- 조율: `measure-sustain.cjs --uncalibrated` → `calibrate-sustain.py`로 새 파일만 재측정해 `sample-calibration.js`의
  해당 항목을 갱신했다. 97.903 Hz(−1.7센트), 유효 창 34개. 첼로 공통값은 중앙값이라 그대로 둔다.
- 음량: `npm run measure:loudness -- --notes`로 첼로 악기 게인 0.89 → 0.76, 음별 게인을 갱신했다. 재실행 결과가 같은 값으로 수렴한다.
  맨 아래 솔은 −3 dB 한도에 닿아 보정 후에도 첼로 기준보다 약 3.2 dB 크다(−19.1 / −22.3 dB). 한도를 넓히지 않는다.
  낮은 음은 같은 dB에서도 작게 들리는 편이라 청감으로 확인한다.
- 측정값을 고정한 테스트 2건(첼로 악기 게인, 첼로 라 칸 음별 게인)을 새 측정값으로 바꿨다.
- 다른 음의 테이크도 같은 문제가 의심되면 이 표와 같은 방식으로 같은 음의 다른 세기·길이 테이크를 먼저 비교한다.
