# 악기마다 다른 붓: 생김새와 붓끝 표현

확인일: 2026-10-03

## 결론

3단계 악기 붓은 13개 악기를 각각 고유한 벡터 그림으로 보여 준다. 그림은 2단계 악기 카드 사진과 같은 생김새를 따른다. 관악기와 가야금은 실제 연주자가 드는 방향(연주 자세)으로 든다. 연주자는 붓 쪽(방금 그린 선 쪽)에 있고, 나팔과 숨결은 앞으로 그릴 쪽(바깥쪽)을 향한다. 그리는 동안에는 악기가 소리 내는 방식대로 움직인다. 활로 긋는 현악기는 활이 줄 위를 오가고, 부는 관악기는 취구·리드에서 숨결이 나간다. 가야금 줄과 대금 청은 떨고, 호른 나팔은 금빛으로 울린다. 붓끝 효과는 악기 소리의 성격(`manifest.js`의 악기 설명)을 모양과 움직임으로 옮긴다. 그림과 효과 성격은 `js/instrument-brush.js`가 맡는다. 도화지 선·레시피·내보내기는 바뀌지 않는다.

`2026-10-03-instrument-brush-drawing.md`의 "별 최대 18개·수명 650ms"는 "효과 최대 18개·악기별 수명 0.6~1.3초"로 바뀐다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 악기 무리별 공용 그림 4종(이전) | 바이올린과 비올라가 같고, 관악기 6종이 같은 막대라 고른 악기를 알아보기 어려움 |
| 2단계 악기 사진을 커서 크기로 축소 | 배경이 섞이고 손가락 마디만 한 크기에서 뭉개짐. 연주 몸짓을 넣을 수 없음 |
| 악기별 벡터 그림 + SVG 안의 몸짓 클래스 | 채택. 작은 크기에서도 부품(턱받침·엔드핀·청공·안족)이 보이고 움직임은 CSS가 제어 |
| 도화지 선 자체를 악기별 질감으로 | 저장·내보내기 그림이 바뀌므로 이번 범위에서 제외 |
| 모든 악기에 같은 별 효과 | 소리 성격의 차이를 보여 주지 못함 |
| 모든 악기를 세워서 같은 각도로 기울임(첫 판) | 가로로 부는 피리·눕혀 뜯는 가야금이 연주하는 모습으로 보이지 않음 |
| 나팔·숨결이 붓끝(방금 그린 선)을 향함(둘째 판) | 지나온 선을 향해 연주하는 것처럼 보임. 학생에게 중요한 건 앞으로 그릴 쪽이라 바깥을 향하도록 바꿈 |
| 악기별 연주 자세(쉴 때·그릴 때 두 자세) | 채택. 그리기 시작하면 악기를 입에 대거나 연주 각도로 들어 올리는 몸짓이 생김 |

## 적용 방향

- 그림은 악기를 알아보게 하는 부품을 살린다.
  - 서양 현악기: 크기 순서(바이올린 < 비올라 < 첼로 < 더블베이스)를 비율로 보인다. 더블베이스는 처진 어깨와 금속 줄감개, 첼로·더블베이스는 엔드핀을 단다. 바이올린·비올라는 턱받침, 바이올린은 미세 조율기를 단다.
  - 서양 관악기: 플루트는 입술판과 가운데가 뚫린 키, 오보에는 붉은 실을 감은 겹리드, 클라리넷은 마우스피스·리가처·고리 키를 단다. 호른은 로터리 밸브와 크게 열린 나팔로 그린다.
  - 국악기: 소금은 짧은 노란 대와 실 감기, 대금은 청공·놋쇠 띠·칠성공, 단소는 검은 대와 U자 취구로 그린다. 해금은 갈고리 머리·주아·복판·원산과 두 줄 사이의 활, 가야금은 열두 줄·비스듬한 안족·부들과 술로 그린다.
- 연주 자세(`POSES`)는 붓끝에서 그림 중심까지의 거리와 기울기를 쉴 때·그릴 때 두 벌로 적는다. CSS 변수(`--pose-*`)로 커서에 넣는다. 그림자는 회전하지 않는 커서에 주어 늘 아래로 떨어진다.
  - 현악기·해금: 세워 든다(첫 판과 같은 자세).
  - 플루트·소금·대금: 몸통이 연주자 오른쪽으로 뻗는 수평 자세다. 학생이 직접 든 시점이라 입 쪽 끝이 붓끝 위에 오고, 몸통은 앞쪽으로 뻗으며 숨결은 선에서 멀어지는 바깥쪽(위)으로 흩어진다. 쉴 때는 끝이 처져 있다가 그릴 때 들어 올린다. 소금·대금은 "늘 수평"으로 든다. 대금은 취구 쪽 끝을 왼쪽 어깨에 얹지만 몸통은 오른쪽으로 수평이다. 운지도 왼손이 취구 쪽 1~3공, 오른손이 4~6공이다([나무위키 대금](https://namu.wiki/w/%EB%8C%80%EA%B8%88), [위키백과 대금](https://ko.wikipedia.org/wiki/%EB%8C%80%EA%B8%88), [국립국악원 국악아카데미 소금](https://academy.gugak.go.kr/dp/pds/HTML3-3-2-2/HTML3-3-2-2-5/HTML3-3-2-2-5-1/HTML3-3-2-2-5-1-2/index.htm)). 반시계로 돌려 드는 관악기는 모두 빛(그러데이션·키 반사광·관 하이라이트)을 그림 오른쪽에서 비춰, 돌린 뒤에도 빛이 위에서 내려오게 한다.
  - 오보에·클라리넷·단소: 마우스피스(붓 쪽, 왼쪽 위)를 문 채 비스듬히 들어 나팔이 앞쪽 아래로 열린다. 그릴 때 마우스피스를 축으로 −26°에서 −40°로 들어 올린다.
  - 호른: 마우스피스는 붓 쪽(왼쪽 위), 나팔은 앞쪽(오른쪽)으로 열린다. 쉴 때 처져 있던 나팔을 그릴 때 거의 가로(−62°에서 −80°)로 들어 올린다.
  - 가야금: 무릎에 눕혀 뜯는 자세로, 머리 쪽 현침이 오른쪽이다.
- 커서 그림은 48×88px(뷰박스 1단위=1px)이다. 그러데이션 id에는 악기 이름을 붙여 겹치지 않게 한다. 마크업은 `DOMParser`로 SVG 노드로 만들어 넣는다(innerHTML을 쓰지 않음).
- 몸짓 클래스: `ib-play`(그리는 동안만 보임)·`ib-bow`·`ib-puff`·`ib-shimmer`·`ib-reed`·`ib-pulse`. 움직임 줄이기 설정에서는 애니메이션을 끄고 연주 자세만 보여 준다.
- 붓끝 효과 표(`TRAITS`)에는 소리 내는 방식(`family`: bow·breath·reed·brass·pluck), 효과 모양(`spark`), 간격, 크기, 방향, 수명, 덧빛을 적는다. 악기별 효과는 다음과 같다.

| 악기 | 소리 성격 | 붓끝 효과 |
| --- | --- | --- |
| 바이올린 | 선명하고 화려함 | 붉은·금빛 별이 튀어 오름 |
| 비올라 | 차분하고 은은함 | 부드러운 빛무리가 천천히 번짐 |
| 첼로 | 깊고 풍부함 | 따뜻한 울림 고리가 부풂 |
| 더블베이스 | 낮고 묵직함 | 납작한 물결이 아래로 가라앉음 |
| 플루트 | 가볍고 투명함 | 바람결이 뒤로 흩날림 |
| 오보에 | 애잔하고 맑음 | 맑은 물방울이 떨어짐 |
| 클라리넷 | 둥글고 부드러움 | 동그란 방울이 떠오름 |
| 호른 | 웅장하고 포근함 | 금빛 후광이 감쌈 |
| 소금 | 청아함 | 십자 반짝임이 스침 |
| 대금 | 깊게 울림 | 긴 바람결이 휘돎 |
| 단소 | 고요함 | 작은 빛이 드문드문 떠오름 |
| 해금 | 애절함 | 떨리는 물결선(농현)이 흐름 |
| 가야금 | 맑게 뜯음 | 겹물결이 퍼짐 |

- 효과는 그리는 동안에만, 동시에 최대 18개까지 만든다. 움직임 줄이기 설정에서는 만들지 않는다.
- 효과를 피울 순간은 `shouldSparkle(trait, motion)` 한 곳에서 정한다. `motion`에는 지난 효과 뒤의 시간·이동 거리와 붓끝이 새 음 칸에 들어왔는지(`newNote`)가 들어 있다. 지금은 모든 악기가 간격·이동 거리 규칙을 함께 쓰고, 소리 내는 방식별 규칙은 이 함수에서 조정한다.
