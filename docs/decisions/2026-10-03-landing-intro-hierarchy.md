# 메인 연출을 먼저 보고 입장하는 순서

확인일: 2026-10-03

## 결론

`2026-10-03-brush-to-melody-landing.md`의 즉시 진입 문구 배치를 변경한다. 사용자가 그림과 음표에 먼저 집중하도록, 처음 약 5초 동안 중앙 문구를 숨긴다. 붓질이 끝나면 **화음 → 그림에 선율을 더하다 → 입장하기** 순서로 부드럽게 나타난다.

상단 로고·갤러리 메뉴, 하단 화음지기 표기, 한자의 작은 설명을 없앤다. 중앙 제목과 문구는 유지하며, 사용자가 고른 붓글씨 느낌을 적용한다. 갤러리 공유 주소의 자동 이동은 유지한다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 중앙의 큰 제목과 채워진 버튼을 처음부터 표시 | 배경 연출보다 먼저 시선을 끈다는 사용자 피드백 |
| 중앙에 입장 버튼만 표시 | 사용자가 제목과 짧은 문구의 유지를 명시하여 제외 |
| 붓질 뒤에 제목·문구·입장 버튼을 차례로 표시 | 채택. 그림과 음악의 연결을 먼저 보여주고 브랜드와 행동을 제시 |

## 적용 방향

- 중앙 글자는 기존 애니메이션 시계에 맞춰 약 5.05초·5.35초·5.65초부터 각각 850ms 동안 나타난다. 일시정지·다시 보기에도 같은 순서를 따른다.
- 보이지 않는 링크는 `visibility: hidden`으로 키보드 포커스와 클릭 대상에서 제외한다.
- JavaScript 또는 Canvas를 사용할 수 없을 때는 중앙 문구와 링크를 즉시 표시한다. 움직임 줄이기 설정에서도 완성된 화면으로 시작한다.
- 이미지 로딩이 늦어도 1.5초 뒤에는 연출을 시작해 입장 링크가 무기한 숨겨지지 않게 한다.
- 중앙에는 Nanum Brush Script를 사용하고, 한자에는 궁서 계열의 로컬 대체 서체를 사용한다. 입장 버튼은 투명한 바탕과 가는 테두리로 정리한다.
- 폰트는 Google Fonts의 텍스트 제공본을 `assets/fonts/landing-brush.ttf`로 보관하고 미리 불러온다. 표시 문자를 바꾸면 폰트 범위도 확인한다.

폰트 출처: [Google Fonts 원본 정보](https://github.com/google/fonts/blob/main/ofl/nanumbrushscript/METADATA.pb). [원본 라이선스](https://github.com/google/fonts/blob/main/ofl/nanumbrushscript/OFL.txt)는 `assets/fonts/OFL-NanumBrushScript.txt`에 함께 보관한다. 다운로드에 사용한 문자 범위는 `화음그림에선율을더하다입장하기`다.
