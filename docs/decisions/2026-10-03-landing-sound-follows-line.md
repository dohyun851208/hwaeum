# 선이 그어질 때 함께 들리는 메인 소리

확인일: 2026-10-03

## 결론

`2026-10-03-picture-melody-landing.md`에서는 소리를 듣기 버튼으로만 냈다. 이를 **선이 그어질 때마다 함께 들리는 소리**로 바꾼다. 사용자가 연출과 소리가 같이 들리기를 원했다. 브라우저는 방문자가 페이지를 누르기 전에는 소리를 막으므로(자동 재생 정책), 다음 순서로 최대한 가깝게 맞춘다.

- 페이지가 열리면 대금 원음을 미리 받아 둔다. 브라우저가 이 사이트의 자동 재생을 허용하면 첫 선부터 대금이 함께 연주된다.
- 허용되지 않으면 연출 동안 소리 스위치가 은은하게 빛난다. 그림이나 스위치를 처음 누르면 그 순간 그어지던 위치부터 소리가 합류한다. 선이 이미 끝났으면 소리와 함께 다시 그린다.
- 버튼은 소리 켜기·끄기 스위치다. 켜져 있을 때 그림을 누르면 선율이 다시 그어지며 연주된다. 방문자가 소리를 끈 뒤에는 그림을 눌러도 선만 다시 그린다.
- 완성 뒤 12초마다 지나가는 빛은 소리 없이 둔다. 교실에 띄워 둔 화면에서 같은 선율이 계속 반복되지 않게 하기 위해서다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 처음부터 무조건 자동 재생 | 대부분의 브라우저가 첫 클릭 전 소리를 막아 단독으로는 불가 |
| 듣기 버튼으로만 재생 | 연출과 소리가 따로 놀고, 방문자가 버튼을 찾아야 함 |
| 자동 재생을 시도하고, 막히면 첫 탭에 진행 중인 선으로 합류 | 채택. 허용되는 환경에서는 처음부터, 그 밖에서는 첫 탭부터 선과 소리가 맞음 |
| 연주 빛이 지날 때마다 소리 재생 | 반복이 잦아 수업 중 방해가 됨. 빛은 소리 없이 둠 |

## 적용 방향

- 선을 그릴 때마다(첫 연출·다시 그리기) 회차 번호를 올린다. 소리가 켜져 있으면 매 프레임에 아직 연주하지 않은 회차인지 확인하고, 현재 선의 위치부터 재생한다. 탭이 숨겨지거나 움직임을 멈추면 소리를 끄고, 다시 움직이면 같은 회차의 현재 위치에서 이어 붙는다.
- 실제 페이지 코드를 오프라인으로 렌더해 확인했다. 그리는 도중 누르면 0.05초 안에 소리가 시작되고, 모든 음이 목표 음높이 ±6 cent 안이다.
- 연주가 끝나고 약 2초 뒤 오디오 장치를 쉬게(`suspend`) 하고, 다음 연주 때 깨운다.
- 링크·버튼을 누른 경우에는 소리를 켜지 않는다. 입장하기를 누르는 순간 소리가 났다가 끊기지 않게 하기 위해서다.
- 움직임 줄이기 설정이나 멈춤 상태에서는 자동 재생하지 않는다. 소리를 켜면 선은 그대로 두고 소리만 낸다.
- 교실 PC에서 처음부터 소리가 나게 하려면 사이트별 자동 재생 허용 설정이 있는 브라우저(엣지·파이어폭스 등)에서 이 사이트를 허용한다. 크롬은 일반 설정으로 사이트별 자동 재생을 켤 수 없어 보통 첫 탭이 필요하다. 허용된 경우의 동작은 크롬 자동 재생 허용 옵션으로 확인했다.
