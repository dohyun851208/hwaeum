# 악기별/음별 선율 음량 보정

결정일: 2026-06-28

> 갱신: 음별 보정 ±3 dB의 예외로 더블베이스(2026-07-02)와 국악 4악기 소금·대금·단소·해금(2026-10-03)은 ±12 dB를 쓴다.
> 악기 크기 측정은 재생과 같은 채널·국악 음색 필터를 거친다 → [음량 전수 점검](2026-10-03-loudness-audit.md)

## 결론

선율 악기 음량은 바이올린을 기준으로 맞춘다. 새 악기나 새 샘플을 넣을 때는 감으로 `audio-engine.js`의 gain을 바꾸지 않고, `npm run measure:loudness`로 안정 구간의 평균 dB를 측정한 뒤 `INSTRUMENT_MELODY_OUTPUT_GAINS`를 갱신한다.

악기 내부의 음별 차이는 `NOTE_MELODY_OUTPUT_GAINS`로 한 번 더 보정한다. 이 보정은 악기별 평균 dB를 기준으로 하되 최대 ±3 dB까지만 적용한다. 원본 샘플의 자연스러운 음색과 세기 차이를 모두 없애지 않고, 특정 음만 갑자기 작거나 크게 들리는 문제를 줄이는 목적이다.

## 비교

| 방식 | 장점 | 단점 | 판단 |
| --- | --- | --- | --- |
| 악기별 기본 gain 1.0 | 구조가 단순함 | 샘플마다 녹음 세기와 후처리가 달라 악기 선택 때 음량이 튐 | 기각 |
| 귀로만 수동 조정 | 빠르게 고칠 수 있음 | 재현이 어렵고 샘플 교체 때 같은 문제가 반복됨 | 기각 |
| 바이올린 기준 측정 보정 | 재현 가능하고 악기 간 체감 음량 차이를 줄임 | 음색 차이 때문에 완전한 동일 체감은 아님 | 채택 |

## 적용 방향

측정은 드로잉에서 실제로 쓰는 기본 음높이 행을 기준으로 한다. 서양 악기는 C장조 15개 행, 국악기는 공통 10개 행을 쓴다. 각 샘플의 안정 구간을 `ffmpeg volumedetect`로 측정하고, RMS 평균에 가까운 `mean_volume`의 에너지 평균을 비교한다.

국악 샘플맵에서 `src`가 있는 항목은 앱이 개별 파일 전체를 재생하므로 파일 전체의 안정 구간을 측정한다. `src`가 없는 항목은 긴 원본 파일에서 `offset/duration` 구간을 잘라 쓰므로 그 구간 안의 안정 구간을 측정한다.

보정값은 완전한 음향 표준화가 아니라 교실 앱에서 악기를 바꿨을 때 갑자기 크거나 작아지지 않게 하는 근사값이다. 새 샘플을 넣은 뒤에는 `npm run measure:loudness` 결과의 `recommendedGain`을 보고 `js/audio-engine.js`와 관련 테스트를 같이 갱신한다.

음별 보정 후보는 `npm run measure:loudness -- --notes`로 확인한다. 출력되는 `NOTE_MELODY_OUTPUT_GAINS` 후보는 악기별 현재 평균을 목표로 계산하며, 각 음의 보정 폭은 ±3 dB를 넘지 않는다. 이 제한을 넘겨야만 괜찮게 들리는 샘플은 코드 gain보다 원본 샘플 선택을 다시 검토한다.
