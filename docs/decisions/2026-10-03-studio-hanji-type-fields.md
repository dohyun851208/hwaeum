# 스튜디오: 밝은 머리, 한 글꼴, 같은 모양의 적는 칸

확인일: 2026-10-03

## 결론

`2026-10-03-studio-ink-frame-renewal.md`의 먹색 머리띠를 사용자가 보고 세 가지를 지적했다. 상단이 너무 검어서 아래 밝은 화면과 따로 놀고 1~5단계 글자가 잘 안 보인다, 글꼴이 중구난방이다, 적는 칸이 통일감이 없다. 그래서 더 크게 고친다.

- **머리**: 어두운 띠를 없앤다. 한지 바탕 위에 먹 글씨 「화음」 로고·낙관, 단계 줄, 그림 칩을 **한 줄**로 둔다. 단계 줄은 ①—②—③—④—⑤ 형태다. 지난 단계는 청록 원, 지금 단계는 먹색으로 채운 원과 굵은 글씨, 다음 단계는 회색 테두리 원으로 표시한다. 단계 글씨는 바탕 대비 4.5:1 이상이다.
- **글꼴**: 로고(연성체 손글씨)를 뺀 모든 글자를 한 가족 **Hwaeum Sans**(Pretendard)로 통일한다. 400·500·600·700 네 굵기만 선언해, 기존 규칙에 흩어진 800·850·900·950 굵기 85곳이 글꼴 매칭으로 700에 모인다. 제목 28px, 소제목 18px, 본문 15px, 칸 이름 14px, 도움말 13px의 다섯 크기로 정리한다. Jua와 Gowun Batang은 스튜디오에서 쓰지 않는다.
- **적는 칸**: 한 줄 칸·여러 줄 칸·#번호 칸·태그 칸·공유 창의 칸이 모두 같은 높이(44px), 테두리, 10px 모서리, 흰 바탕, 15px 글씨, 같은 안내 글 색과 같은 청록 초점 테두리를 쓴다. 칸 이름은 모두 칸 위에 둔다(4단계 제목·작곡가 포함). 칸 안에 칸이 든 묶음(#번호, 태그)은 바깥만 칸으로 보이게 하고, 배경 구간 시간 칸만 작은 크기로 둔다.
- 5단계 학생 입장은 알약 모양 대신 [# 번호][갤러리 코드][들어가기] 세 칸으로, 선생님 만들기는 2열 격자로 맞춘다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 먹색 머리띠 + 밝은 화면(이전) | 위아래가 따로 놀고 어두운 바탕 위 단계 글씨가 흐림 |
| 한지 위 한 줄 머리 + 먹 글씨 | 채택. 화면과 같은 종이 위에 있어 이어지고, 단계 상태가 색과 굵기로 분명함 |
| 기존 규칙의 굵기·크기를 하나씩 수정 | 85곳 이상이라 놓치기 쉬움 |
| 네 굵기만 선언한 글꼴 가족으로 매칭 정리 | 채택. 기존 규칙을 건드리지 않고 굵기가 네 단계로 모임 |

## 적용 방향

- 글꼴은 `assets/fonts/hwaeum-sans.css`에 있다. Pretendard v1.3.9 동적 부분집합에서 네 굵기만 골라 `Hwaeum Sans`로 다시 선언한 것으로, 글꼴 파일은 jsDelivr CDN에서 필요한 글자 조각만 받는다(OFL, 저작권 표기는 파일 머리에 있음). CDN에 닿지 못하면 맑은 고딕으로 표시된다.
- 모든 변경은 `styles.css` 끝의 `@renewal-2026-10` 구간에 있다. 토큰은 `body:not(.channel-body)`에 두어, 화음 갤러리(`channel.html`)가 변경 전과 픽셀 단위로 같음을 확인했다.
- 칸 공통 규칙은 `:where()`로 우선순위를 낮췄다. 그래서 여러 줄 칸·작은 메모 칸·시간 칸 같은 세부 규칙이 덮어쓸 수 있다. `.field-invalid`의 빨간 테두리도 같은 구간에서 다시 정의한다.
- 머리 한 줄은 `.topbar`를 `display: contents`로 풀어 `.atelier` 격자 첫 줄에 로고·단계·칩을 놓는 방식이다. 마크업은 바꾸지 않았다.
- `npm test` 358개와 `tools/smoke.cjs`(178개 확인)가 통과했다. 1280×720과 1600×900에서 다섯 단계와 공유 창을 캡처해 확인했다.

## 덧붙임: 낱말 중간 줄바꿈 없애기

사용자가 5단계 안내문이 "…만듭니 / 다."처럼 이상한 곳에서 줄이 바뀐다고 지적했다. 한글은 기본값으로 글자 사이 어디서나 줄이 바뀌기 때문이다. 그래서 `body`에 `word-break: keep-all`(띄어쓰기에서만 줄바꿈)과 `overflow-wrap: break-word`(칸보다 긴 낱말만 예외)를 걸고, 제목에는 `text-wrap: balance`, 문단·칸 이름에는 `text-wrap: pretty`를 준다. 스튜디오와 갤러리 공통 규칙이며, 메인(`index.html`)에도 `keep-all`을 건다.

화면에 보이는 모든 글자를 한 글자씩 측정하는 스크립트로 확인했다. 줄이 바뀐 자리 앞이 띄어쓰기가 아니면 낱말 중간 줄바꿈으로 센다. 고치기 전에는 1280·1600 너비 모두에서 5단계 안내문 한 곳이 낱말 중간에서 끊겼다. 고친 뒤 다섯 단계(국악 탭 포함)·공유 창·갤러리·메인을 1280·1366·1440·1600·1920 너비에서 재면 **0곳**이다. 텍스트가 칸을 넘치는 곳은 없다. 레이아웃이 바뀐 곳은 5단계 안내문과 4단계 안내 글 두 곳뿐이고, 갤러리는 변경 전과 같다. 캔버스로 그리는 표지 글자는 한 줄 말줄임이라 해당이 없다.

## 덧붙임: 2단계 카드와 메모를 한 장으로

사용자가 2단계 카드의 위(배경·악기 카드)와 아래(「어떤 느낌인가요?」 메모)가 따로 논다고 지적했다. 둘은 마크업상 형제여서(버튼 안에 입력칸을 넣을 수 없다) 테두리·모서리·바탕을 각자 가지고 있었고, 카드 아래 모서리를 펴는 규칙도 뒤의 공통 카드 규칙에 덮여 있었다.

- 테두리·14px 모서리·바탕·선택 표시(테두리색 + 바깥 빛 3px)는 바깥 슬롯(`.atmosphere-card-slot`·`.instrument-card-slot`)만 갖는다. 안쪽 카드와 메모는 테두리·그림자·떠오름 없이 그 위의 내용이다.
- 메모 칸 왼쪽과 아래 여백은 카드 제목과 같은 16px다(테두리 포함 17px로 측정).
- 악기 카드는 악기 빛깔이 카드 위에서 아래로 한 번에 옅어지게 슬롯 바탕에 둔다. 그림 부분은 제 높이를 지키고 남는 높이는 메모 쪽이 받는다. 그래서 한 줄의 색 띠와 메모 칸이 같은 높이에 선다(예시 답안을 펼친 카드가 있어도 같음).
- 2단계 제목과 설명 사이 간격을 다른 단계와 같은 8px로 맞췄다(전에는 36px).

## 덧붙임: 글자 크기 바닥과 3단계 팔레트

사용자가 글자가 너무 작지 않은지 점검하고, 3단계 악기·효과음 팔레트를 정리해 달라고 했다. 다섯 단계와 공유 창의 보이는 글자를 모두 재 보니 가장 작은 글자는 10.6px(3단계 악기 이름)였고, 효과음 이름 10.9px를 비롯해 11~13px 글자가 많았다.

- **읽는 글자는 14px 이상**으로 한다. 카드 설명·안내 문장·도움말·칸 이름·「예시 답안 보기」·읽기 값 이름(악기·그림·길이)이 대상이다. 단계 번호·「1단계」 같은 작은 제목·초 눈금·건반 번호 배지·출처 같은 **숫자·장식 표시만 12~13px**를 쓴다. 고친 뒤 다시 재면 14px 미만은 이 표시들뿐이다.
- **3단계 팔레트**: 왼쪽 이름 칸에 「악기」와 흰 상자 속 「서양」「국악」이 겹쳐 떠 있던 배치를 버린다. 「악기」·「효과음」 제목(16px) → 「서양」·「국악」 작은 이름(14px, 흐린 색) → 88px 같은 크기 칸으로 정리하고, 모든 칸을 왼쪽 한 선에 맞춘다. 칸 안 그림 뒤 흰 상자는 없앤다. 악기 칸 아래 3px 색 띠는 그 악기가 그리는 선의 색이다(2단계 카드 띠와 같은 뜻). 고른 악기는 그 색 테두리와 빛으로 표시한다. 효과음 도장은 펜·지우개처럼 도구라서 켜지면 먹색으로 채운다. 「소리 추가하기」 제목도 같은 16px로 맞췄다.
- 검사: 낱말 중간 줄바꿈 0곳, 글자가 잘리거나 넘치는 곳 없음(가로로 스크롤되는 30초 도화지의 보이지 않는 초 눈금만 바깥에 있음), `npm test` 358개·스모크 통과.

## 덧붙임: 자리가 어색하던 안내 두 개

사용자가 두 안내문의 자리와 말투를 지적했다.

- **1단계 그림 안내**: 「표지에는 직접 만든 그림이나 사용 허락을 받은 이미지만 올려 주세요.」가 화면 맨 아래, 생각 칸보다 뒤에 홀로 떠 있었다. 「직접 그린 그림이나 허락받은 그림만 올려 주세요.」로 줄여 그림 칸 안의 올리기 안내 바로 아래로 옮긴다. 그림을 올리면 칸과 함께 사라진다. 이 화면에서 쓰는 낱말에 맞춰 「표지」를 「그림」으로 바꿨다. 올린 뒤의 상태(파일 이름 적용됨·이미지 파일만 올릴 수 있어요)는 `#picStatus`가 그림 바로 아래, 그림 왼쪽 끝에 맞춰 보여 준다. 비어 있으면 자리를 차지하지 않는다.
- **5단계 선생님 안내**: 만들기 단추 아래의 긴 작은 글씨(관리자 공통 코드로 생성이 가능하며… / 학생은 교사가 알려 준…)를 없앤다. 대신 두 카드의 제목 아래에 한 줄씩 둔다. 선생님 카드는 「만든 갤러리의 번호와 코드를 학생들에게 알려 주세요.」, 학생 카드는 「선생님이 알려 준 갤러리로 들어가요.」다. 관리자 공통 코드(8624)는 칸 안내 글자에 그대로 있다. 두 카드의 첫 입력 줄도 같은 높이에 맞춰진다.
- 이 문구를 고정하던 `test/user-facing-copy.test.js`·`test/channel-secondary-pass.test.js`의 단언도 새 문구로 고쳤다.
- 함께 고친 문제: 오류 안내(`.upload-status.error`)가 빨간색 대신 회색으로 보였다. 도움말 규칙이 `:is(#hashtagHelp, …)`처럼 목록 안에 아이디를 섞어, 목록 전체가 아이디 우선순위를 가졌기 때문이다. 아이디는 목록 밖 별도 선택자로 뺐다. 그 바람에 2단계 카드 설명이 13px로 돌아가서, 카드 설명 규칙 자체를 14px로 고쳤다. 스튜디오 다섯 단계 캡처는 의도한 1·5단계 외에는 변경 전과 같다(재생 단추 깜박임 제외).
