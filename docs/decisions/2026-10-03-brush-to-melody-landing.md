# 붓질에서 선율로 이어지는 화음 메인

확인일: 2026-10-03

## 결론

메인 페이지는 이름의 유래인 **畵(그림 화) + 音(소리 음)**를 계속 꼬이며 흐르는 붓질로 표현한다. 왼쪽 **畵**를 지나면 청록색 물감과 잎 모양이 나타나고, 아래 중앙 **音**을 지나면 금빛 음표가 두 줄기로 풍성하게 휘감긴다. 중앙에는 화음, “그림에 선율을 더하다”, 스튜디오 진입 링크만 남겨 설명 문구를 줄인다.

사용자가 제안한 이 방향은 기존 메인 화면의 원형 세 개와 畵·和·音 소개를 대체한다. 스튜디오의 악기 붓과 선 표현은 `2026-10-03-instrument-brush-drawing.md`에 기록한다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 완성된 그림 위에 한자와 음표를 반복 이동 | 붓질과 음악의 인과관계가 약하고 시작 버튼 표시가 늦음 |
| 한자 구역을 통과하며 그림과 음표가 생기는 나선형 흐름 | 채택. 이름의 의미를 위치와 움직임으로 전달 |
| 영상 또는 새 렌더링 라이브러리 도입 | 정적 페이지에서 SVG·Canvas로 처리 가능하므로 도입하지 않음 |

## 적용 방향

- `index.html` 내부 CSS·SVG·Canvas·classic script로 구성한다. 앱 모듈이나 로드 순서는 변경하지 않는다.
- 배경은 `assets/hero/brush-melody.webp`로 저장한다. 기존 배경 원본은 보존한다.
- 붓 경로의 길이로 위치와 두 한자 구역을 계산한다. 약 5초의 첫 붓질 이후에도 아홉 가닥의 선과 96개 입자가 계속 흐른다. 음 구역 뒤에서는 반대 위상의 음표 줄기를 추가한다.
- 경로는 401개 지점으로 미리 샘플링한다. Canvas 해상도 배율은 1.5 이하, 갱신은 최대 약 30fps로 제한한다.
- 시작 링크는 연출과 이미지·웹폰트 로딩을 기다리지 않는다. JavaScript 없이도 완성된 그림과 링크가 표시된다.
- 움직임 정지·재개와 다시 보기를 제공한다. 움직임 줄이기 설정에서는 완성된 정지 화면으로 시작하며, 버튼을 누르면 사용자가 직접 움직임을 켤 수 있다.
- 문서가 숨겨지면 프레임을 취소하고, 다시 보이면 이전 시점에서 재개한다.
- 기존 `shareChannel`·`channel` 쿼리와 해시를 이용한 갤러리 이동을 보존한다.
- 데스크톱과 낮은 노트북 창을 기준으로 검증한다.

내장 imagegen 도구로 생성하고 ffmpeg의 WebP quality 82로 변환했다. 최종 크기는 약 115 KiB다.
