# 선율을 그리는 마법의 악기 붓

확인일: 2026-10-03

## 결론

선율 도화지에서는 사용자가 그린 선을 하나의 매끈한 획으로 보여준다. 보정된 음을 나타내던 짧은 가로 막대는 숨기고, 선택한 악기를 포인터 옆에 띄운다. 그리는 동안 붓끝에서 작은 별이 잠깐 흩어진다. 음높이 보정과 음악 데이터는 그대로 유지한다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 선분마다 둥근 끝을 겹쳐 렌더 | 반투명 선의 겹친 곳이 구슬처럼 진해짐 |
| 한 획을 하나의 경로로 렌더 | 채택. 얇은 중심선과 부드러운 외곽만 남김 |
| 보정 음을 가로 막대로 계속 표시 | 그림에 없는 직선이 겹쳐 시각적으로 복잡함 |
| 악기·별을 도화지에 직접 그리기 | 저장·이미지 내보내기에 장식이 섞이므로 사용하지 않음 |
| 별도 DOM에 벡터 악기와 짧은 별 효과 표시 | 채택. 실제 드로잉과 입력 좌표를 유지 |

## 적용 방향

- `drawing.js`의 선율 렌더에서 음 보정 막대를 제외한다. 리듬 표시와 재생용 음 배열은 유지한다.
- 획은 외곽과 중심을 각각 한 번씩 렌더해 선분 끝의 중첩을 없앤다. 악기별 색과 국악/서양 축 변환은 유지한다.
- 선택 악기 형태의 SVG 커서를 도화지 위에서만 표시한다. 지우개·효과음 도장은 각 도구의 기존 커서를 사용한다.
- 작은 별은 그리는 동안만 만들며 최대 18개, 수명 650ms로 제한한다. 움직임 줄이기 설정에서는 별을 만들지 않는다.
- 단계 이동, 포인터 이탈·취소, 창 비활성화 시 악기 커서를 숨긴다. 장식은 레시피·내보내기 캔버스에 포함하지 않는다.
- 연속 획과 보정 막대 제거는 렌더 테스트로, 악기 전환·도장·지우개·단계 이동·반짝임 정리는 실제 브라우저로 확인한다.
