# 화음 갤러리: 먹빛 전시실

확인일: 2026-10-03

## 결론

메인과 스튜디오의 리뉴얼에 맞춰 화음 갤러리(`channel.html`)도 같은 언어로 바꾼다. 갤러리는 메인의 밤을 잇는 전시실이다. 메인의 먹색 벽에 학생 작품을 크림색 매트를 두른 액자로 걸고, 아래에 이름표를 단다.

- **벽**: 갤러리 사진 배경과 나무 선반을 걷어 낸다. 메인과 같은 먹색(#101d20)에 아주 옅은 한지 결과 천장 빛만 둔다. 작품이 없는 방(입구·잠김·빈 전시)에서는 메인의 산수화가 아래쪽에 어둡게 깔린다.
- **한눈에 보기**: 작품을 같은 크기의 정사각 액자(10px 크림 매트)로 한 줄에 맞춰 건다. 화면 너비에 따라 5~6줄이 된다. 위에서 비추는 은은한 빛을 두고, 마우스를 올리면 액자가 4px 떠오른다. 그림 위에 겹쳐 쓰던 제목 띠 대신 그림 아래에 이름표(제목 16px · 작곡가 14px · 단어 14px 금빛)를 둔다. 제목과 작곡가는 「제목 (작곡가)」 한 줄에서 두 줄로 나눈다.
- **커버플로우**: 같은 액자를 쓰고, 가운데 작품에만 이름표를 띄운다. 무대 높이를 화면에 맞춰 1280×720에서도 작품 번호(1 / 10)까지 한 화면에 들어온다.
- **입구·잠긴 갤러리**: 메인처럼 화면 가운데에 낙관, 갤러리 이름, [번호][코드|열기] 칸을 크게 모은다. 전에는 빈 어두운 방의 오른쪽 위 작은 칸에서만 코드를 넣을 수 있었다.
- **머리**: 어두운 띠를 없애고 벽 위에 메뉴 단추 · 낙관 + 갤러리 이름 · 보기 전환 · 번호 칸을 둔다. 노란 채움 대신 크림 채움을 쓴다(보기 전환 선택, 열기, 주 단추).
- **작품 보기**: 정보 칸을 제목 → 작곡가·배경음악·악기 → 시도 횟수 → 감상글 → 단어 순으로 정리한다. 「스튜디오에서 보기」(크림)와 「다른 갤러리에 복사하기」(테두리)는 한 줄 글자로 쓴다. 감상글이 길어도 단추는 정보 칸 아래에 늘 보인다.
- **메뉴·이름 바꾸기 창**: 같은 먹색 판(#14272b)에 크림 글자를 쓴다. 칸은 스튜디오와 같은 모양(44px, 10px 모서리)이다.
- **글꼴**: 스튜디오와 같은 Hwaeum Sans(Pretendard 4굵기)를 쓰고 Jua는 쓰지 않는다. 읽는 글자는 14px 이상이다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 갤러리 사진 배경 + 나무 선반 + 노란 강조(이전) | 배경 속 다른 그림이 학생 작품과 겨루고, 나무 선반과 노란색이 새 메인·스튜디오와 어긋남 |
| 스튜디오처럼 밝은 한지 갤러리 | 전시실의 깊이가 사라지고 메인의 밤과 이어지지 않음 |
| 메인의 먹색 벽 + 매트 액자 + 이름표 | 채택. 메인과 같은 세계이고, 작품이 가장 밝은 것이 됨 |
| 입구를 따로 새 화면으로 만들기 | 입력칸·스크립트가 두 벌이 됨. 같은 칸을 화면 상태에 따라 가운데로 옮김 |

## 적용 방향

- 모든 겉모양 변경은 `styles.css` 끝의 `@gallery-renewal-2026-10` 구간에 있다. 토큰은 `.channel-body`에 두어 스튜디오 화면은 바뀌지 않는다(스튜디오 다섯 단계 캡처가 변경 전과 같음을 확인했다).
- `js/channel.js`는 두 곳만 바뀐다.
  - `updateHeader()`가 `body[data-gallery-state]`에 `entry`·`loading`·`locked`·`open`·`empty`를 적는다. CSS는 이 값으로 입구 화면을 고른다. `channel.html`은 첫 그림이 깜박이지 않게 `loading`으로 시작한다.
  - `createAlbumCard()`가 제목(`workTitle`)과 작곡가(`.channel-album-composer`)를 따로 만든다. 합친 이름은 화면 읽기용 `aria-label`에 남는다. 이를 고정하던 `test/cover-ui.test.js`의 단언도 함께 고쳤다.
- 입구 화면은 머리의 제목 칸과 번호 칸을 `position: fixed`로 화면 가운데에 모은다. 그래서 머리(`.channel-topbar`)에 `backdrop-filter`를 두지 않는다. 두면 고정 위치의 기준이 머리로 바뀐다.
- 액자 위 조명은 가장자리를 마스크로 흐려 두었다. 마스크가 없으면 다음 줄 조명이 시작하는 곳에 옅은 가로줄이 생긴다.
- 기존 테스트가 고정한 옛 규칙(머리 격자, 번호 칸 폭, 커버플로우 이름표 위치 등)은 지우지 않고 위에 덮었다.
- 확인: 1280×720·1600×900에서 입구·잠김·빈 전시·한눈에 보기·커버플로우·작품 보기·메뉴·이름 바꾸기를 캡처했다. 14px 미만은 「갤러리 관리」 같은 작은 머리말뿐이고, 낱말 중간 줄바꿈은 0곳이다. API 없이 여는 로컬 환경에서도 오류 없이 빈 전시 화면이 나온다. `npm test` 358개와 스모크가 통과했다.
