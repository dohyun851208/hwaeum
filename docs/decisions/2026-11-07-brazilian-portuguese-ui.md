# 한국어·브라질 포르투갈어 언어 선택

브라질 교사 연수에서 기존 화음을 활용할 수 있도록 사용자가 언어 선택 기능을 요청했다.

- 한국어를 기본으로 두고 `Português (Brasil)`을 제공한다. 선택은 `hwaeum.language`로 이 브라우저에 저장한다. 저장소에 접근할 수 없어도 화면 내 전환은 동작한다.
- 기존 classic script 구조를 유지한다. `locale-pt-BR.js` 사전 다음에 `i18n.js`를 로드하고, 정적 문구는 `data-i18n`, 동적 표시는 `HwaeumI18n.t`를 사용한다. UI에 새로 생기는 텍스트·접근성 속성은 MutationObserver로 사전의 문구만 번역한다. 원문을 별도로 기억하므로 한국어로 되돌릴 수 있다.
- 메인·제작 단계·갤러리의 주요 안내와 조작 문구가 1차 적용 범위다. 아직 사전에 없는 상세 설명과 오류 문구는 한국어로 표시한다.
- 작품 이름·학생 메모·악기/배경 식별자·레시피 저장 형식은 언어 전환으로 바꾸지 않는다. UI를 다시 그릴 때 메모는 기존 state에서 복원한다.
- 2026-11-09 추가 요청으로 연주 화면의 효과음·음이름·시간·횟수와 접근성 안내 번역을 보완하고, 커밋·푸시 후 공식 Vercel 프로덕션에 배포한다.
