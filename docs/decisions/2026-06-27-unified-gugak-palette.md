# 국악기 드로잉 팔레트 통일

확인일: 2026-06-27

## 결론

소금·대금·해금·가야금·산조아쟁의 드로잉 팔레트는 모두 같은 10칸을 쓴다.

`G-A-C-D-E-G-A-C-D-E`

## 비교

| 방식 | 장점 | 단점 | 판단 |
| --- | --- | --- | --- |
| 악기별 `playableMidi`에 맞춰 팔레트 축소 | 음원 샘플맵과 직접 맞추기 쉬움 | 악기를 바꿀 때 줄 수와 음 이름 순서가 달라져 학생이 혼란스러움 | 폐기 |
| 국악기 공통 10칸 팔레트 | 악기를 바꿔도 같은 위치가 같은 음 이름을 뜻함 | 샘플맵에 등록되지 않은 구간은 가까운 구간에서 피치 보정될 수 있음 | 채택 |

## 적용 방향

`js/manifest.js`에 공통 `GUGAK_PALETTE_MIDI`를 두고 모든 국악 선율 악기의 `playableMidi`가 같은 목록을 참조하게 한다. 국악풍 스타일의 `highMidi`는 E5(76)까지로 두어 `music-core.buildScale()`도 같은 10칸을 만든다.

국악 음원은 긴 프레이즈 MP3에서 구간을 잘라 쓰므로, “원음에 음이 있는지”와 “`js/sample-maps.js`에 직접 구간으로 등록됐는지”는 별도 문제다. 팔레트 통일은 먼저 적용하고, 필요하면 샘플맵 구간 검출과 보정은 별도 작업으로 다룬다.
