# 스튜디오 내부를 먹 액자 + 한지 작업면으로 정리

확인일: 2026-10-03

## 결론

사용자는 메인 페이지에 비해 스튜디오(5단계 위저드)의 완성도가 떨어진다고 느꼈다. 문구가 적고 간결한 점은 지금도 좋다고 했다. 그래서 문구와 동작은 그대로 두고 **겉모양만** 메인과 같은 언어로 바꾼다.

- **먹 액자**: 머리띠와 단계 줄을 메인의 먹색(#101d20) 한 덩어리로 잇는다. 로고는 메인 제목 서체(연성체 부분집합)로 쓴 「화음」, 작은 「스튜디오」, 붉은 畵音 낙관이다. 현재 단계는 금빛 원 숫자와 아래 금선으로 표시한다.
- **한지 작업면**: 오래 작업하는 화면은 밝게 둔다. 바탕은 배경 그림·광택 대신 결이 살짝 보이는 한지색이다. 한 화면은 종이 한 장이고, 안쪽의 큰 판(그리기 판·완성 판·공유 판)은 테두리와 배경 없이 여백으로만 나눈다.
- **제목 서체**: 화면 제목은 Jua 대신 Gowun Batang(명조 계열)이다.
- **버튼**: 노란 채움 대신 먹색 단추(주 행동)와 가는 선 단추(보조)다. 4단계는 「화음 갤러리에 공유하기」가 주 행동이고 「저장」은 보조다.
- **같은 말 반복 제거**: 2단계의 「배경 음악 고르기」 소제목, 카드마다 붙은 「내 느낌」 표시 등 화면 제목과 겹치는 말은 화면에서 숨기고 읽기 도구에만 남긴다. 카드와 감상 메모 칸은 한 장의 카드로 잇는다.
- **그림 칸**: 1단계의 빈 칸은 금선 점선에 아이콘과 두 줄만 둔다. 그림을 올리면 흰 매트를 두른 액자가 된다. 4단계 표지도 같은 흰 매트 액자다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 기존: 크림색 유리판 + 노란 강조 + Jua 제목, 판 안에 판 | 상자가 겹겹이고 노란색이 많아 메인의 차분한 먹·금 톤과 어긋남 |
| 스튜디오 전체를 메인처럼 어둡게 | 교실에서 오래 쓰는 그리기·글쓰기 화면이 답답하고 읽기 힘듦 |
| 머리띠만 먹 액자, 작업면은 밝은 한지 | 채택. 브랜드는 메인과 이어지고 작업 화면은 밝고 조용함 |

## 적용 방향

- 모든 변경은 `styles.css` 끝의 `@renewal-2026-10` 구간에 모은다. 이 구간은 기존 규칙을 덮어쓰기만 하며, 다음 정리 때 원래 규칙과 합칠 수 있다. 문구·마크업 구조·스크립트는 바꾸지 않는다. 마크업 변경은 머리띠 로고뿐이다.
- 색·서체 토큰은 `body:not(.channel-body)`에 정의해 스튜디오에만 적용한다. 어두운 화음 갤러리(`channel.html`)는 변경 전과 픽셀 단위로 같음을 확인했다.
- 낙관은 메인의 SVG를 `assets/brand/hwaeum-seal.svg`로 꺼내 공유한다(벡터라 WebP 대상 아님).
- 3단계는 화면 높이 레이아웃이 따로 있어, 키가 큰 화면에서 머리띠 행이 늘어나지 않게 `align-content: start`를 준다.
- `npm test` 358개와 `tools/smoke.cjs` 통합 스모크가 통과했다. 1280×720·1366×768·1600×900에서 5단계를 캡처해 확인했다.
