# 화음 갤러리 번호와 코드 길이 축소

확인일: 2026-07-01

## 결론

화음 갤러리 입장 정보는 교실에서 칠판에 적고 학생이 빠르게 입력하는 값이므로 짧게 제한한다.

- **갤러리 번호**: 숫자 최대 4자리
- **갤러리 코드**: 숫자 4~6자리

## 비교

| 방식 | 장점 | 단점 | 판단 |
| --- | --- | --- | --- |
| 번호 최대 6자리, 코드 최대 12자리 | 충돌 가능성이 낮고 긴 코드 설정 가능 | 입력칸이 넓어지고 학생 입력 부담이 커짐 | 폐기 |
| 번호 최대 4자리, 코드 4~6자리 | UI가 간결하고 교실에서 읽고 입력하기 쉬움 | 번호 공간이 줄어듦 | 채택 |

## 적용 방향

- 클라이언트와 서버 정규화가 같은 제한을 쓰도록 맞춘다.
- `channel.html`과 `studio.html`의 `maxlength`를 번호 4자리, 코드 6자리로 둔다.
- 갤러리 헤더의 입장 폼 폭도 최대 입력 길이에 맞춰 줄인다.
