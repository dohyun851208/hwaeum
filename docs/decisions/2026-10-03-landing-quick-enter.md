# 메인 우측 하단: 움직임 멈추기 대신 바로 시작하기

확인일: 2026-10-03

## 결론

메인 우측 하단의 **움직임 멈추기** 단추를 없애고, 그 자리에 같은 모양의 동그란 **→ 바로 시작하기** 링크(`#quick-enter`, `studio.html`)를 둔다. 입장 버튼은 연출 뒤 약 6~7.5초에 나타나므로, 두 번째 수업부터 다시 오는 교사·학생은 매번 기다려야 했다. 사용자는 "아는 사람만 쓸 수 있게" 구석에 조용한 바로가기를 원했고, 움직임 멈추기는 학생에게 필요 없다고 했다.

## 비교

| 방식 | 판단 |
| --- | --- |
| 우측 상단·하단에 "바로 들어가기" 글자 단추 | 문구가 늘고 같은 곳으로 가는 단추가 둘이 됨. 교실에서는 다들 이것부터 눌러 연출(앱 설명 역할)을 건너뜀 |
| 화면 탭으로 건너뛰기 | 첫 탭은 이미 소리 합류에 쓰므로 겹침 |
| 움직임 멈추기 옆에 아이콘 추가 | 단추가 셋이 되고, 멈추기는 연출 도중에 누르면 12초까지 입장 버튼이 숨는 문제가 남음 |
| 움직임 멈추기를 빼고 그 자리에 → 아이콘 링크 | 채택. 보이는 문구는 그대로이고, 소리 단추와 같은 모양이라 처음 온 사람의 눈은 연출에 머묾 |

## 적용 방향

- 아이콘은 입장 버튼과 같은 → 화살표로, 같은 곳으로 간다는 뜻을 잇는다. 글자는 화면낭독용(`sr-only`)과 마우스를 올렸을 때의 `title`에만 둔다.
- 소리·바로가기 단추는 그림이 준비되면(늦어도 1.5초) 나타나므로, 입장 버튼보다 먼저 누를 수 있다.
- 움직임이 힘든 사용자를 위한 길은 운영체제의 "움직임 줄이기"(`prefers-reduced-motion`)로 남는다. 이때 메인은 완성된 그림으로 시작한다.
- `2026-10-03-brush-to-melody-landing.md`의 움직임 제어 단추는 이 결정으로 없어진다.
