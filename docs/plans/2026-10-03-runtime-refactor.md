# 런타임 리팩토링 계획과 검증

## 기준

- 시작 시 작업 폴더의 UI·음원·보정 변경을 기준으로 삼는다. 기존 변경을 되돌리지 않는다.
- 시작 기준: `npm test` 358개 통과.
- 빌드 없는 classic script, 공개 API, 레시피 저장 형식, 음원과 측정 게인을 유지한다.
- 소스 복사본은 작업 폴더 밖 임시 디렉터리에 보관하고 이번 변경만 비교한다.

## 작업 순서

1. HTML에서 실제 스크립트 순서를 읽는 공통 검증 로더를 만들고 테스트·측정·스모크의 중복 목록을 정리한다.
2. 오디오 엔진에서 지속음 루프·샘플 버퍼 가공을 별도 모듈로 분리한다. 재생·정지 상태와 게인 표는 엔진에 둔다.
3. 스튜디오의 레시피 직렬화·음 생성·사용 악기 계산을 순수 모듈로 옮긴다. 현재 선택과 저장 작품의 상태가 섞이지 않게 검증한다.
4. 드로잉의 피치 축·캔버스 렌더를 입력·실행 취소 처리에서 분리한다. 공개 DrawingCanvas API는 유지한다.
5. 갤러리 로컬 저장소를 서버 통신·표지 생성에서 분리하고 트랜잭션·객체 URL의 수명을 검증한다.
6. 전체 테스트, jsdom 스모크, 로컬 HTTP 서버의 실제 Chromium에서 제작·복원·재생·내보내기·갤러리 흐름을 검증한다.
7. 모듈 책임·로드 순서와 변경 근거를 지침 쌍 및 ADR에 기록한다.

## 검증 기록

| 검증 | 결과 |
| --- | --- |
| 시작 기준 `npm test` | 358개 통과 |
| 완료 기준 `npm test` | 376개 통과, 실패·건너뜀 0 |
| `npm run test:smoke` | 전체 통과(오디오·캔버스 스텁) |
| `npm run test:browser` | 실제 Chrome, 로컬 HTTP, 1600×1000 데스크톱에서 전체 통과 |
| 변경 전후 비교 | 악기 13개의 같은 검증 레시피를 48 kHz 스테레오로 렌더한 PCM 해시 및 도화지 픽셀 해시 일치 |
| 실제 음원 | MP3 샘플 394개 디코드, 13개 악기 출력 모두 비무음 |
| 제작 흐름 | 그림 업로드·포인터 드로잉·실제 샘플 미리듣기·실행 취소·서양/국악 축 전환·성찰·태그·저장·복원·재생/일시정지/재개/정지 통과 |
| 내보내기 | 드로잉 PNG, 음악 WebM, 드로잉 WebM 실제 다운로드 통과 |
| 저장/갤러리 | 새로고침 후 시도 복원, 실제 IndexedDB에서 갤러리 생성·잘못된 코드 거부·게시·복사·감상·스튜디오 복사본 열기·작품/갤러리 삭제 통과 |
| 비동기 응답 | 예전 갤러리 요청의 늦은 성공과 실패가 마지막 선택을 덮어쓰지 않음 |
| 정적 점검 | JS/CJS 41개 문법 정상, AGENTS/CLAUDE 3쌍 일치, `git diff --check` 통과 |
| 브라우저 오류 | 실행 오류 및 실패한 음원 HTTP 응답 0 |

브라우저 결과·캡처·다운로드는 `output/refactor-review/`에 있다. `REFACTOR_BASELINE_DIR`에 작업 시작 시 소스 복사본을 지정해 비교했다. 오디오 비교에는 UI의 비동기 미리듣기 준비와 분리된 AudioEngine을 사용하며, 실제 위저드 재생·펜 소리는 별도의 UI 흐름에서 확인한다. 단위 테스트는 외부 라이브러리 없이 실행하고, 스모크와 브라우저 도구는 선택적 개발 도구로 유지한다.

## 완료한 구조 변경

| 기존 모듈 | 시작 → 완료 줄 수 | 분리한 책임 |
| --- | --- | --- |
| `audio-engine.js` | 2247 → 2004 | 지속음 루프·샘플 가공을 `audio-samples.js`로 |
| `drawing.js` | 1505 → 917 | 피치 축·가이드·획 렌더를 `drawing-renderer.js`로 |
| `studio.js` | 2251 → 1975 | 순수 레시피 변환·감상 입력을 `studio-recipe.js`·`studio-reflection.js`로 |
| `share-store.js` | 767 → 436 | IndexedDB·객체 URL 수명을 `share-local-store.js`로 |
| `channel.js` | 1581 → 1468 | 쓰이지 않는 이미지 생성 경로 제거·오래된 요청 응답 차단 |

스크립트 로더의 중복 목록과 API 여섯 개의 동일한 오류 응답도 공통화했다. 기존 작업 폴더의 음악 규칙·MP3·게인·조율·화면 스타일을 유지했다. Vercel 배포와 실제 원격 Blob 저장은 실행하지 않았다.
