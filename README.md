# 그림 BGM 만들기

학생이 그림을 올리고, 분위기·악기·음계를 고른 뒤 **드로잉으로 30초 BGM을 만드는** 교실용 웹 창작 도구입니다.
Song Maker(음계·박자 자동 보정) + Paint with Music(드로잉→소리, 장면 캔버스) + BandLab(레이어 합주)의 장점을 결합했습니다.

빌드/프레임워크 없이 동작하는 **단일 정적 웹앱**입니다.

## 실행

이 폴더는 **자족형**입니다. 음원(`sound/`)·이미지·코드가 모두 안에 있어, 폴더를 통째로 복사/zip해서 어느 컴퓨터로 옮겨도 그대로 동작합니다. 단, `file://`(파일 더블클릭)에서는 브라우저 보안상 음원 fetch가 막혀 합성음만 나오므로 **로컬 서버로** 여세요.

가장 쉬운 방법: 이 폴더의 **`웹으로 열기.bat`** 더블클릭 (서버 + 브라우저 자동 실행). 또는 직접:

```text
python -m http.server 4173      # 이 폴더(sound-drawing-tool)에서 실행
```

브라우저에서(데스크탑·마우스 환경 기준):

```text
http://localhost:4173/index.html
```

> 끄려면 서버 창에서 Ctrl+C. 음원이 정상 로드되면 하단에 "실제 음원을 우선 사용…", 실패하면 ⚠ 경고가 표시됩니다.
> git/GitHub에는 대용량 음원(`sound/`)을 넣지 않습니다 — 다른 컴퓨터로는 **폴더를 복사**해 옮기세요.

## 제작 흐름 (5단계)

1. **그림·길이** — 그림을 먼저 올리고(이후 위쪽에 계속 표시), 15/30/45초 선택. 길이에 따라 드로잉 팔레트 구간 수가 정해집니다(30초=10초×3칸).
2. **분위기** — 고요한·긴장되는·밝은·이국적인·평화로운·활기찬. 카드를 누르면 매칭된 배경 음원을 **미리듣기**하고, 고른 분위기가 곡의 배경이 되며 **화면 색(무드 틴팅)** 도 함께 바뀝니다. **내 배경 음원 추가** 카드로 직접 올린 음원(mp3·wav)도 분위기로 쓸 수 있습니다(현재 세션 한정).
3. **악기** — 서양(바이올린·첼로·플루트·오보에 등) / 국악(대금·해금·가야금 등) / 전자(신디).
4. **선율(음계)** — 밝음(장음계)·차분함(단음계)·신비로움(온음음계)·자연스러움(5음음계)·국악풍(5음+시김새). 모두 으뜸음을 도(C)로 맞춰 음계의 성격이 또렷이 구분됩니다. **선율형/리듬형** 토글.
5. **드로잉·완성** — 가로=시간(그리는 속도 무관), 세로=음높이(악기 음역 ≈2옥타브, 화면 격자=실제 연주 음). **여러 번 나눠 그릴 수 있고**(획이 그린 대로 남음), **지우개**로 일부만 지울 수 있습니다. 음은 레가토로 이어지고, **재생 시 재생바**가 위치를 보여줍니다. 음계로 자동 보정 + 4/4 리듬 자동완성. 시도 저장·비교, 액자 표지에서 재생, WAV·커버 PNG 내보내기, 공유 링크.

## 핵심 동작

- **드로잉→음악**: 그린 선을 가로 위치 기준으로 박자 격자에 재샘플링하므로 **그리는 속도와 무관**. 음높이는 선택 음계의 가장 가까운 음으로 자동 보정.
- **시김새(국악)**: 국악기·국악풍 선택 시 꺾음·흘러내림·떠는음을 피치 곡선으로 적용.
- **시도(테이크) 저장·비교**: 저장하는 것은 "레시피"(설정+드로잉 선)뿐 — 오디오는 저장하지 않으므로 용량 부담이 없습니다(localStorage). 재생 시 매번 재합성.
- **내보내기**: 완성곡을 오프라인 렌더링해 **WAV**로, 표지를 **PNG**로 다운로드. 서버 없이 학생 PC에 저장됩니다.
- **공유 링크**: 레시피를 URL에 담아(오디오 없이, 수 KB) 같은 사이트에서 열면 그대로 복원.
- **실제 음원 우선, 합성음 대체**: 파일을 못 불러온 층만 자동으로 합성음으로 대체합니다.

## 파일 구조

```
index.html         5단계 위저드 마크업
styles.css         갤러리·아틀리에 디자인 + 무드 틴팅(CSS 변수)
js/music-core.js   순수 로직: 음계·피치 보정·시간 재샘플링·리듬·시김새·레시피 코덱·WAV 인코딩
js/manifest.js     음원·분위기·악기·음계 데이터  ← 음원 추가/교체는 주로 여기만 수정
js/audio-engine.js Web Audio 합주(라이브+오프라인 렌더)·피치 시프트·시김새·합성 폴백
js/drawing.js      캔버스 드로잉·가이드/팔레트 렌더·보정 음 오버레이
js/takes.js        시도 저장·비교(localStorage)·썸네일
js/studio.js       위저드 흐름·업로드·무드 틴팅·재생·내보내기·공유
```

## 음원 추가/교체

`js/manifest.js`에서 수정합니다.

- **배경 음원(분위기)**: `backgrounds.<id>`에 `label`과 `src`(예: `sound/배경(freesound)/고요한.wav`)를 넣고, `atmospheres`에 같은 `id`로 항목을 추가하면 분위기 카드와 1:1로 매칭됩니다. 카드 클릭 시 그 `src`가 미리듣기로 재생됩니다. (선생님이 화면에서 직접 올린 음원은 그 세션에만 유지됩니다.)
- **선율 악기**: `melodies.<악기>`에 `src`와 기준음 `baseMidi`를 지정합니다(단일음 샘플은 피치 시프트, 긴 구절은 `sampleMode: "phrase"`).
- **효과음**: `effects`에 추가하고 장면의 `effectIds`에 연결합니다.

## 테스트

```powershell
npm test          # 순수 로직 단위 테스트 (node --test, 의존성 없음)
```

통합 스모크(선택, jsdom 필요 — 오디오/캔버스는 스텁):

```powershell
npm i jsdom ; node tools/smoke.cjs
```

브라우저 콘솔에서 `window.SoundDrawing` 으로 상태 확인이 가능합니다:
`getStateSummary()`, `play()`, `stop()`, `exportWav()`, `buildRecipe()`, `loadRecipe(recipe)`, `setStep(n)`.
