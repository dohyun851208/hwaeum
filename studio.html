#

선생님

화음 갤러리 관리하기

관리자 번호(8624)로 화음 갤러리 생성이 가능하며, 교사가 화음 갤러리의 번호, 이름, 비밀번호를 설정하여 화음 갤러리를 만듭니다.
학생은 교사가 설정한 화음 갤러리 번호 + 비밀번호를 통해 들어갈 수 있습니다.
화음 갤러리 삭제 시에는 화음 갤러리 비밀번호가 필요하며, 화음 갤러리 안의 음악도 함께 삭제됩니다.

국악 음원 출처: 국립국악원 디지털음원 (공공누리 제1유형·출처표시)
